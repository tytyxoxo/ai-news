## 1. Anthropic เปิดตัว Fable 5.2 และ Mythos 5.2 พร้อมลดราคา Fable

TechCrunch รายงานว่า Anthropic ปล่อยโมเดลรุ่นล่าสุดสองตัวเมื่อวันจันทร์ คือ Mythos 5.2 และ Fable 5.2 โดยบริษัทระบุว่าทั้งคู่ดีขึ้นในด้านการเขียนโค้ด การให้เหตุผล และการมองภาพ รวมถึงสื่อสารกับผู้ใช้ชัดเจนขึ้น จุดที่สะดุดตาคือ Fable ลดราคาจาก 10 เหลือ 8 ดอลลาร์ต่อล้านโทเค็นอินพุต ทำให้ถูกกว่า GPT-6 Astra ซึ่งเป็นคู่แข่งหลัก และตอบกลับเร็วขึ้นราว 30% ในทุกระดับ effort ส่วนโหมดเร็วพิเศษคิดราคาสองเท่า

สำหรับนักพัฒนา การลดราคาพร้อมความเร็วที่เพิ่มขึ้นช่วยให้งานเอเจนต์ที่รันนานคุ้มค่าขึ้นโดยไม่ต้องเปลี่ยนสถาปัตยกรรม และการรองรับนโยบาย zero data retention ผ่านระบบ Enterprise Frontier Safeguards ก็แก้จุดติดขัดที่องค์กรเอ่ยถึงมานาน อย่างไรก็ตาม การเปิดตัวเกิดขึ้นหลังรายงานของ METR ที่ระบุว่าโมเดลภายในช่วยเร่งงานพัฒนา AI ของ Anthropic ราว 2 เท่า แม้ยังมีความไม่แน่นอนอีกมาก ซึ่งทำให้ประเด็นความปลอดภัยถูกจับตาไปพร้อมกัน

**จับตา:** ลองรันงานโค้ดยาวๆ ของทีมบน Fable 5.2 เทียบต้นทุนและเวลากับรุ่นเดิม และติดตามว่าข้อสรุปของ METR จะกระตุ้นการกำกับดูแลหรือไม่

ที่มา: [TechCrunch](https://techcrunch.com/2026/11/09/anthropic-releases-new-mythos-and-fable-models-amid-rsi-concerns/)

## 2. Meta เปิดตัว Muse Ember โมเดลเล็กราคาถูกสำหรับงานเอเจนต์

TechCrunch รายงานว่า Meta Superintelligence Lab ปล่อย Muse Ember โมเดลที่เบาและคุ้มค่าที่สุดของห้องแล็บ ออกแบบมาสำหรับงานที่เอเจนต์ทำซ้ำทั้งวัน เช่น การเรียกเครื่องมือ งานย่อยด้านโค้ด การจัดเส้นทางคำสั่ง การดึงข้อมูล และการอ่านเอกสารยาว ค่าอินพุตอยู่ที่ 10 เซนต์ต่อล้านโทเค็น Meta ใช้คะแนนรวมของ Artificial Analysis เพื่อชี้ว่า Ember ถูกและเก่งกว่า Haiku ของ Anthropic และ Luna ของ OpenAI และราคาสูสีกับโมเดลโอเพนซอร์สอย่าง DeepSeek V4.1 Flash

แนวคิดที่ Meta เสนอคือให้โมเดลใหญ่อย่าง Muse Wonder วางแผนและกำหนดกฎ แล้วส่งโมเดลเล็กไปทำงานซ้ำนับหมื่นเคส เช่น ในระบบบริการลูกค้า วิธีนี้ลดต้นทุนต่อหนึ่งงานได้มากสำหรับธุรกิจที่รันเอเจนต์ปริมาณสูง แต่ตัวเลขเปรียบเทียบทั้งหมดมาจากการประกาศของ Meta เอง ผู้ใช้จึงควรทดสอบกับงานจริงของตนก่อนย้ายระบบ โดยเฉพาะงานที่ต้องการความแม่นยำสูง

**จับตา:** ทดสอบ Ember กับงานย่อยซ้ำๆ ในเอเจนต์ของคุณ แล้ววัดต้นทุนต่อหนึ่งงานเทียบกับโมเดลที่ใช้อยู่

ที่มา: [TechCrunch](https://techcrunch.com/2026/11/09/meta-releases-muse-ember-a-new-lightweight-model-for-agent-execution/)

## 3. Claude Code เผลอทำให้ความลับรั่วไหลบน GitHub หลายพันรายการ

Ars Technica รายงานผลวิจัยของ Apiiro ที่พบความลับจำนวนหลายพันรายการ ทั้งรหัสผ่านฐานข้อมูล API token และข้อมูลล็อกอิน root ปนอยู่ในไฟล์ตั้งค่าของ Claude Code ที่ถูกอัปโหลดขึ้นรีโพสิทอรีสาธารณะ สาเหตุมาจากวิธีจัดการการอนุมัติคำสั่งเชลล์ เมื่อผู้ใช้เลือก "Yes, and don't ask again" ระบบจะบันทึกเป็นกฎใน .claude/settings.local.json ซึ่งบางครั้งเก็บตัวคำสั่งตามที่พิมพ์ไว้ รวมถึงข้อมูลลับที่ฝังอยู่ในคำสั่งนั้น

ปัญหานี้ไม่ร้ายแรงนักหากไฟล์อยู่ในเครื่อง และ Anthropic ระบุในเอกสารว่าไฟล์นี้ถูกเพิ่มใน global .gitignore ซึ่งมักกันไม่ให้ถูกแชร์ แต่ผลสำรวจชี้ว่ายังมีไฟล์หลุดออกไป ทีมพัฒนาจึงควรมองไฟล์ตั้งค่าของเครื่องมือ AI เป็นข้อมูลอ่อนไหว ตรวจรีโพของตนด้วยเครื่องมือสแกนความลับ และหลีกเลี่ยงการใส่รหัสผ่านตรงๆ ในคำสั่งที่อนุมัติแบบถาวร ส่วนรายละเอียดเต็มของการแก้ไขจากฝั่ง Anthropic ยังต้องรอติดตาม

**จับตา:** ค้นรีโพของทีมหาไฟล์ .claude/settings.local.json ที่ถูก commit ไว้ แล้วเปลี่ยนความลับที่พบทันที

ที่มา: [Ars Technica](https://arstechnica.com/ai/2026/11/claude-code-settings-files-expose-thousands-of-secrets-on-github/)

## 4. Anthropic เดินหน้า IPO ท่ามกลางตลาดผันผวน ตั้งเป้าระดมทุนสูงสุด 6.93 หมื่นล้านดอลลาร์

TechCrunch รายงานตาม Wall Street Journal ว่า Anthropic ยังเดินหน้าแผนเข้าตลาดหลักทรัพย์ แม้ตลาด Nasdaq เพิ่งเทขายหนักและเกิดข่าวอื้อฉาวของซีอีโอคนสำคัญในวงการ AI บริษัทวางแผนกำหนดช่วงราคาในสัปดาห์นี้ และเริ่มซื้อขายในวันพฤหัสบดีหรือศุกร์ของสัปดาห์หน้า Bloomberg อ้าง Reuters ว่าบริษัทตั้งเป้าระดมทุนได้สูงสุด 69.3 พันล้านดอลลาร์ตามเอกสารที่ยื่น ขณะที่นักลงทุนสถาบันบางรายผลักดันให้ตั้งมูลค่าต่ำกว่าเป้า 1.5 ล้านล้านดอลลาร์ที่คุยกันเมื่อสัปดาห์ก่อน

มูลค่าที่ออกมาจะถูกใช้เป็นมาตรวัดความแข็งแรงของกระแส AI โดยรวม เพราะ OpenAI เพิ่งถูกประเมินที่ 1.25 ล้านล้านดอลลาร์ หลังระดมทุนได้ 11 พันล้านดอลลาร์ น้อยกว่าที่ตั้งใจไว้ 20 พันล้าน สำหรับผู้ใช้และนักพัฒนา การเป็นบริษัทมหาชนอาจทำให้การเปิดเผยข้อมูลการเงินและความเสี่ยงชัดขึ้น แต่ตัวเลขทั้งหมดยังเป็นข้อมูลจากรายงานสื่อและอาจเปลี่ยนก่อนเปิดซื้อขายจริง

**จับตา:** ติดตามช่วงราคา IPO ที่จะประกาศสัปดาห์นี้ ซึ่งบอกได้ว่านักลงทุนยังเชื่อมั่นมูลค่าบริษัท AI ระดับแนวหน้าแค่ไหน

ที่มา: [TechCrunch](https://techcrunch.com/2026/11/09/anthropic-reportedly-plans-to-move-forward-with-ipo-plans/)

## 5. กูเกิลเพิ่มชิป TPU รุ่นที่ 8 อีก 2 รุ่น เน้นเข้ารหัสแรมและแก้คอขวดหน่วยความจำ

Blognone รายงานว่ากูเกิลเปิดตัว TPU รุ่นที่ 8 เพิ่มอีกสองรุ่น ต่อจาก TPU 8t และ 8i ที่เปิดตัวในงาน Google I/O ได้แก่ TPU 8tx และ TPU 8i Max ซึ่งตอบโจทย์ตลาดเฉพาะทางกว่าเดิม TPU 8tx ใช้เทคโนโลยีเข้ารหัสแรมของ AMD โดยตัวชิปเป็น AMD EPYC รุ่นที่ 5 ช่วยให้องค์กรที่กังวลเรื่องข้อมูลรั่วไหลฝึกโมเดลบนคลาวด์ได้สบายใจขึ้น ส่วน TPU 8i Max เพิ่ม SRAM บนชิปเป็น 768MB และ HBM เป็น 384GB แบนด์วิดท์ 17.2TB/s

ชิปรุ่น Max มุ่งแก้ปัญหา memory bandwidth ที่เป็นคอขวดของการผลิตโทเค็นใน LLM ซึ่งเป็นจุดที่กระทบความเร็วและต้นทุนการให้บริการโดยตรง น่าสังเกตว่ากูเกิลระบุว่าใช้ AlphaChip ซึ่งเป็น AI ออกแบบชิปช่วยลดงานบางส่วนจากหลายสัปดาห์เหลือไม่กี่ชั่วโมง สะท้อนทิศทางที่ AI ถูกใช้พัฒนา AI มากขึ้น แต่ตัวเลขประสิทธิภาพเป็นข้อมูลจากกูเกิลเอง ผู้ใช้ Google Cloud ต้องรอดูราคาและการทดสอบอิสระ

**จับตา:** รอราคาและวันที่เปิดให้บริการของ TPU 8i Max บน Google Cloud เพื่อเทียบต้นทุนต่อโทเค็นกับ GPU
