## 1. Nvidia ทุ่ม 1.5 พันล้านดอลลาร์ลงทุนศูนย์ข้อมูล SoftBank หนุนโปรเจกต์ OpenAI

TechCrunch รายงานเมื่อ 17 สิงหาคม 2569 ว่า Nvidia จะลงทุน 1.5 พันล้านดอลลาร์ใน SB Energy บริษัทศูนย์ข้อมูลที่เชื่อมโยงกับ SoftBank และโครงการ Ports-Pike ของ OpenAI ใกล้เมือง Cincinnati รัฐโอไฮโอ ดีลนี้การันตีให้ Nvidia เป็นผู้จัดหาโครงสร้างพื้นฐานประมวลผลแต่เพียงผู้เดียวของศูนย์ข้อมูลแห่งนี้

การลงทุนสะท้อนว่า Nvidia ไม่ได้เป็นแค่ซัพพลายเออร์ฮาร์ดแวร์อีกต่อไป แต่กลายเป็นนักลงทุนโดยตรงในโครงสร้างพื้นฐานที่ลูกค้ารายใหญ่อย่าง OpenAI ต้องพึ่งพา ช่วยผูกมัดความสัมพันธ์ทางธุรกิจและการันตีดีมานด์ชิประยะยาว สำหรับองค์กรที่พึ่งพา cloud compute นี่คือสัญญาณว่าการแข่งขันแย่งชิงกำลังประมวลผล AI ยังร้อนแรงต่อเนื่อง

**จับตา:** โมเดลผูกขาดแบบนี้จะกลายเป็นมาตรฐานใหม่ของดีลศูนย์ข้อมูล AI หรือไม่

## 2. Groq ระดมทุนเพิ่ม 350 ล้านดอลลาร์ ปรับทิศจากชิป AI สู่ธุรกิจ Neocloud

TechCrunch รายงานเมื่อ 17 สิงหาคม 2569 ว่า Groq ระดมทุนรอบใหม่ 350 ล้านดอลลาร์ นำโดยกองทุน Disruptive และมี Nvidia ร่วมลงทุนด้วย ส่งผลให้บริษัทมีมูลค่ากว่า 3.5 พันล้านดอลลาร์ เงินทุนนี้จะใช้ผลักดันการปรับทิศทางธุรกิจจากผู้ผลิตชิป AI เฉพาะทางสู่การเป็นผู้ให้บริการ neocloud หรือโครงสร้างพื้นฐาน GPU แบบคลาวด์เต็มรูปแบบ

การปรับตัวของ Groq ชี้ให้เห็นว่าแม้แต่บริษัทชิปที่มีเทคโนโลยีเฉพาะทางก็ต้องขยายสู่การให้บริการโครงสร้างพื้นฐานโดยตรง เพื่อแข่งขันกับผู้เล่นรายใหญ่ในตลาดคลาวด์ AI ที่กำลังเติบโตเร็ว การที่ Nvidia เข้าร่วมลงทุนยังสะท้อนว่าคู่แข่งด้านฮาร์ดแวร์บางรายอาจกลายเป็นพันธมิตรเชิงกลยุทธ์ในสมรภูมิ AI infrastructure ที่ต้องการเงินทุนมหาศาล

**จับตา:** Groq จะสามารถแข่งขันด้าน neocloud กับผู้เล่นรายใหญ่อย่าง AWS หรือ CoreWeave ได้มากน้อยเพียงใด

ที่มา: [TechCrunch](https://techcrunch.com/2026/08/17/groq-raises-350m-to-fuel-its-pivot-from-ai-chips-to-neocloud/)

## 3. Cursor เปิดตัวแพลตฟอร์มโฮสต์โค้ด Origin จังหวะ GitHub ล่มพอดี

VentureBeat รายงานเมื่อ 17 สิงหาคม 2569 ว่า Cursor เริ่มเปิดให้ผู้ใช้แบบเสียเงินทดลองใช้ Origin แพลตฟอร์มโฮสต์โค้ดของตัวเอง ในเช้าวันจันทร์ ซึ่งเกิดขึ้นพร้อมกับเหตุการณ์ GitHub ล่มนานกว่า 6 ชั่วโมง 42 นาที ทำให้อัตราความผิดพลาดของ pull request, issue และ API พุ่งขึ้นเกือบ 20%

จังหวะเวลาที่ตรงกันทำให้ Cursor กลายเป็นทางเลือกที่น่าสนใจทันที และสะท้อนว่า AI agent กำลังเปลี่ยนเกณฑ์การเลือกแพลตฟอร์มโฮสต์โค้ดของนักพัฒนา จากเดิมที่ GitHub ครองตลาดแทบไร้คู่แข่ง Cursor มองเห็นช่องว่างจากการที่ workflow ของนักพัฒนายุค AI agent ต้องการความเสถียรและการผนวกรวมกับเครื่องมือ AI ที่แน่นแฟ้นกว่าเดิม

**จับตา:** นักพัฒนาจะเริ่มย้ายโปรเจกต์จาก GitHub มา Origin จริงจังหรือเป็นเพียงกระแสชั่วคราว

ที่มา: [VentureBeat](https://venturebeat.com/infrastructure/cursor-launches-origin-code-hosting-platform-as-github-outage-exposes-opening-in-ai-coding-race)

## 4. Alibaba เปิดตัว HappyShrimp โมเดล AI แต่งเพลงเวอร์ชันเบต้า

Bloomberg รายงานเมื่อ 17 สิงหาคม 2569 ว่า Alibaba เปิดตัวเวอร์ชันเบต้าของ HappyShrimp 1.0 โมเดล AI สร้างเพลงที่สามารถสร้างทำนอง เรียบเรียงดนตรี เนื้อเพลง และเสียงร้องได้จากพรอมต์ข้อความเพียงประโยคเดียว นับเป็นอีกก้าวของ Alibaba ในการขยายพอร์ตโมเดล AI เชิงสร้างสรรค์ครอบคลุมหลายโมดัลิตี้ต่อจากโมเดลวิดีโอและภาพที่เปิดตัวไปก่อนหน้า

การเปิดตัวนี้ตอกย้ำว่าบริษัทเทคจีนกำลังรุกตลาด generative AI ด้านสื่อสร้างสรรค์อย่างรวดเร็ว ไม่จำกัดแค่ข้อความหรือภาพเหมือนคู่แข่งสหรัฐฯ ส่วนใหญ่ สำหรับครีเอเตอร์และธุรกิจเพลง เครื่องมือแบบนี้อาจลดต้นทุนการผลิตเพลงประกอบคอนเทนต์ลงอย่างมาก แต่ก็เปิดคำถามเรื่องลิขสิทธิ์และผลกระทบต่ออาชีพนักแต่งเพลงในระยะยาว

**จับตา:** คุณภาพเสียงร้องและลิขสิทธิ์เพลงที่สร้างจาก HappyShrimp จะเป็นประเด็นถกเถียงต่อไปหรือไม่

ที่มา: [Bloomberg](https://www.bloomberg.com/news/articles/2026-08-17/alibaba-launches-ai-music-generation-model-happyshrimp-in-beta)

## 5. รัฐมนตรี อว. ชี้ไทยต้องเร่งวางพื้นฐาน AI ให้แน่น หลังสหรัฐฯ กดดันพันธมิตรเลือกข้าง

ประชาชาติธุรกิจรายงานว่า ยศชนัน วงศ์สวัสดิ์ รัฐมนตรีว่าการกระทรวงการอุดมศึกษา วิทยาศาสตร์ วิจัยและนวัตกรรม ระบุว่าสหรัฐฯ กำลังกดดันให้ประเทศพันธมิตรกว่า 35 ประเทศเลือกข้างในศึกเทคโนโลยี AI ระหว่างสหรัฐฯ กับจีน และย้ำว่าไทยจำเป็นต้องเร่งสร้างพื้นฐานข้อมูลและความรู้ด้าน AI ให้แข็งแกร่งไม่ว่าจะเลือกใช้เทคโนโลยีจากค่ายใด

ประเด็นนี้สะท้อนว่าการแข่งขัน AI ระดับโลกไม่ได้จำกัดอยู่แค่บริษัทเทคยักษ์ใหญ่ แต่ลามมาถึงระดับนโยบายรัฐที่ต้องเลือกจุดยืนทางภูมิรัฐศาสตร์ รัฐมนตรีเตือนว่าหากไทยไม่มีพื้นฐานวิทยาศาสตร์และเทคโนโลยีที่แข็งแรงพอ จะตกอยู่ในสถานะถูกต่อรองตลอดเวลา ไม่ว่าผลจากการเลือกข้างจะออกมาเป็นอย่างไร การลงทุนพัฒนาบุคลากรและโครงสร้างพื้นฐานในประเทศจึงเป็นทางออกที่ยั่งยืนกว่าการพึ่งพาเทคโนโลยีนำเข้าเพียงอย่างเดียว

**จับตา:** ไทยจะมีแผนลงทุนโครงสร้างพื้นฐาน AI ในประเทศที่เป็นรูปธรรมออกมาเมื่อใด
