## 1. Anthropic เปิดตัว Claude Meetings ส่ง AI เข้าวิดีโอคอลเพื่อลงมือทำงานระหว่างประชุม

Anthropic ประกาศชุดฟีเจอร์สำหรับที่ทำงานเมื่อวันอังคาร ตัวหลักคือ Claude Meetings ที่ให้ทีมเพิ่ม Claude เข้าวิดีโอคอลในฐานะผู้เข้าร่วมที่ทุกคนมองเห็น Claude จะติดตามบทสนทนาแล้วเริ่มทำงานทันที เช่น ร่างแผนที่กำลังคุยกัน วางไทม์ไลน์บนไวต์บอร์ด ตอบคำถามในแชตของการประชุม และดึงข้อมูลจากแอปทำงานที่เชื่อมต่อไว้ อย่างตัวเลขของปีก่อน เมื่อวางสาย โน้ต รายการงาน และเอกสารที่สร้างไว้จะอยู่ใน claude.ai พร้อมกันนี้ยังเปิดตัว Claude Whiteboards และ Claude Sheets ด้วย

ความเคลื่อนไหวนี้ตามหลัง OpenAI ที่เพิ่งเปิดเครื่องมือทำงานร่วมกับ ChatGPT เมื่อไม่กี่สัปดาห์ก่อน และ Meta ที่ส่ง Muse agent สร้างมินิแอปตามงาน สะท้อนว่าค่าย AI ใหญ่กำลังแข่งกันกลายเป็น "ชุดออฟฟิศ" เพื่อท้าชน Microsoft และ Google โดยตรง สำหรับองค์กร จุดเปลี่ยนสำคัญคือช่องว่างระหว่าง "คุยเสร็จ" กับ "เริ่มทำ" ที่แคบลง แต่ก็มาพร้อมคำถามเรื่องสิทธิ์เข้าถึงข้อมูลในแอปที่เชื่อมต่อ และความแม่นยำของสิ่งที่ AI สรุปจากบทสนทนาสด ซึ่งทีม IT ควรวางนโยบายก่อนเปิดใช้วงกว้าง

**จับตา:** องค์กรจะยอมให้ AI ที่เข้าถึงข้อมูลภายในนั่งอยู่ในห้องประชุมได้มากแค่ไหน และการแข่งขันชุดออฟฟิศ AI จะบีบให้ Microsoft กับ Google ตอบโต้อย่างไร

## 2. Google เปิด Gemini Decisions API ตัดสินใจแบบปิดหลายร้อยข้อในรอบเดียว พร้อมค่าความมั่นใจ

Google เปิดตัว Gemini Decisions API ซึ่งขับเคลื่อนด้วยโมเดลใหม่ Gemini Decision 1 (gemini-decision-1) ผ่าน Gemini API ใน Google AI Studio จุดเด่นคือรับอินพุตหลายรูปแบบ ทั้งข้อความ ภาพ เสียง วิดีโอ และ PDF ได้สูงสุด 256K โทเค็น พร้อมคำถามอิสระได้ถึง 1,000 ข้อ แล้วคำนวณค่าความมั่นใจของแต่ละคำตอบในรอบเดียว รองรับคำถามแบบใช่/ไม่ใช่ ตัวเลือก และการให้คะแนนตามเกณฑ์ (rubric) มีคู่มือสำหรับ Python, JavaScript และ REST

แนวคิดเบื้องหลังคือการแยกงาน "เลือกจากตัวเลือกที่มีจำกัด" ออกจากงานสร้างข้อความ เพราะระบบเอเจนต์จำนวนมากเสียเวลาและค่าใช้จ่ายไปกับการให้ LLM เขียนคำตอบยาวเพียงเพื่อตัดสินว่าจะเรียกเครื่องมือไหนหรือเนื้อหาผิดนโยบายหรือไม่ developer จึงนำไปใช้ทำ model routing, policy check หรือ grading ได้ถูกลง และได้ค่าความน่าจะเป็นมาตั้ง threshold เองได้ ข้อควรระวังคือคำว่า calibrated เป็นคำกล่าวอ้างของ Google เอง ควรทดสอบกับข้อมูลจริงของตัวเองก่อนใช้ตัดสินเรื่องสำคัญ

**จับตา:** ลองย้ายขั้นตอน routing หรือ moderation ในระบบเอเจนต์มาใช้ endpoint นี้ แล้วเทียบค่าใช้จ่ายและความแม่นยำกับการเรียก LLM แบบเดิม

ที่มา: [Google AI](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)

## 3. DeepMind เปิดตัว AlphaGenome 2 ทำนายผลของการกลายพันธุ์ DNA ในเซลล์มนุษย์หลายร้อยชนิด

Google DeepMind ประกาศ AlphaGenome 2 โมเดลลำดับ DNA รุ่นใหม่ที่เชื่อมชีววิทยาระดับเซลล์เดี่ยวเข้ากับพันธุศาสตร์มนุษย์ โดยทำนายว่าลำดับ DNA และความแปรผันทางพันธุกรรมส่งผลต่อเซลล์มนุษย์เฉพาะชนิดอย่างไร ครอบคลุมหลายร้อยชนิดเซลล์ ต่อยอดจาก AlphaGenome รุ่นแรกเมื่อปีที่แล้วที่ทำนายผลในระดับเนื้อเยื่อกว้างๆ และ AlphaGenome Atlas ที่รวบรวมคำทำนายสำหรับการเปลี่ยนตัวอักษรเดียวที่เป็นไปได้ทั้ง 9 พันล้านตำแหน่งในจีโนมมนุษย์

โจทย์ที่ AlphaGenome 2 พยายามแก้คือ แม้ทุกเซลล์มี DNA ชุดเดียวกัน แต่แต่ละชนิดเปิดปิดยีนต่างกัน และการกลายพันธุ์เล็กๆ อาจส่งผลเฉพาะในเซลล์บางชนิด การทำนายระดับเซลล์จึงช่วยนักวิจัยคัดกรองว่าตัวแปรทางพันธุกรรมใดน่าจะเป็นต้นเหตุโรคจริงก่อนลงทุนทำการทดลองในห้องแล็บ อย่างไรก็ดี นี่ยังเป็นการทำนายจากโมเดล ซึ่งต้องพิสูจน์ด้วยการทดลองจริงก่อนนำไปใช้ทางคลินิก และความแม่นยำย่อมขึ้นกับคุณภาพข้อมูลเซลล์ที่ใช้ฝึก

**จับตา:** การเปิดให้นักวิจัยภายนอกเข้าถึงโมเดลและผลการตรวจสอบอิสระว่าคำทำนายระดับเซลล์ตรงกับผลทดลองจริงมากน้อยเพียงใด

ที่มา: [Google DeepMind](https://deepmind.google/blog/alphagenome-2-deciphering-how-cells-read-dna-to-better-understand-disease/)

## 4. Microsoft พบเทคนิค Lazarus ฝังประตูหลังในโมเดลด้วยการปลุก "นิวรอนที่หลับอยู่"

นักวิจัยของ Microsoft เปิดเผยเทคนิคชื่อ Lazarus ที่สามารถเขียนโปรแกรมใหม่ให้นิวรอนที่ปกติไม่ได้ใช้งานในโมเดล AI ทำให้เอเจนต์ที่ดูทำงานปกติลงมือรันคำสั่งอันตรายเมื่อเจอตัวกระตุ้นที่ซ่อนไว้ ประตูหลังแบบนี้ฝังได้โดยไม่ต้องฝึกโมเดลใหม่ ตรวจพบยากด้วยการทดสอบทั่วไป และยังผ่านการประเมินความปลอดภัยมาตรฐานได้ อันตรายเป็นพิเศษกับเอเจนต์ที่เข้าถึงเครื่องมือหรือเทอร์มินัล เพราะอาจแอบดาวน์โหลดโค้ดผู้โจมตี ขโมยข้อมูลลับ หรือรันคำสั่งทำลายระบบ

งานนี้ย้ำว่าความปลอดภัยของ AI ไม่ได้อยู่แค่ที่ prompt หรือ guardrail แต่รวมถึง "น้ำหนักโมเดล" ในฐานะซัพพลายเชนซอฟต์แวร์ ทีมที่ดาวน์โหลด open-weight model จากแหล่งที่ไม่ชัดเจนแล้วให้สิทธิ์รันคำสั่งจึงมีความเสี่ยงสูง Microsoft ระบุว่า Foundry ตรวจที่มาของโมเดลและผูกกับผู้เผยแพร่ที่เชื่อถือได้ และกำลังพัฒนาการสแกนน้ำหนักด้วย AI กับการเซ็นโมเดลด้วยการเข้ารหัส แต่ควรจำไว้ว่าเป็นบล็อกของผู้ขายบริการที่มีผลิตภัณฑ์เกี่ยวข้อง

**จับตา:** ตรวจสอบที่มาและ checksum ของโมเดล open-weight ที่ใช้อยู่ และจำกัดสิทธิ์เทอร์มินัลของเอเจนต์ให้แคบที่สุดตั้งแต่วันนี้

## 5. Netflix ทดลองแท็บ AI Discover ให้เลือกเรื่องดูจากอารมณ์ แทนการเลื่อนหาไม่รู้จบ

Netflix เพิ่มแท็บใหม่ชื่อ AI Discover บนแอปสำหรับทีวี เปิดให้สมาชิกกลุ่มเล็กๆ ทดลองวิธีหาเรื่องดูแบบใหม่ เบื้องหลังคือ "ชั้นระบบอัจฉริยะ" (Intelligence Layer) ที่ Netflix พัฒนาขึ้น ซึ่งปรับคำแนะนำตามสิ่งที่ผู้ใช้บอกแบบเรียลไทม์และเรียนรู้ต่อเนื่อง ฟีเจอร์แรกใช้ "ธีม" เป็นจุดตั้งต้น เช่น Something Light สำหรับคนอยากดูอะไรเบาๆ หรือ Scare Me สำหรับสายหลอน โดยแต่ละธีมมีคลิปตัวอย่างประกอบ

ปัญหาที่ Netflix ยอมรับเองคือคลังเนื้อหาใหญ่ขึ้นทุกปีจนผู้ใช้เลื่อนดูหน้าปกจนหมดเวลาก่อนได้เริ่มดู การเปลี่ยนจากหมวดหมู่ตายตัวมาเป็นการค้นตามอารมณ์และบริบท สะท้อนทิศทางของระบบแนะนำที่กำลังเปลี่ยนจากการเดาจากประวัติการดูอย่างเดียว ไปสู่การโต้ตอบกับความต้องการ ณ ขณะนั้น สำหรับธุรกิจแพลตฟอร์มคอนเทนต์ นี่คือตัวอย่างการใช้ AI แก้ "ความเหนื่อยจากการเลือก" ซึ่งกระทบเวลาการรับชมโดยตรง แม้ยังเป็นเพียงการทดลองในวงจำกัด

**จับตา:** Netflix จะขยาย AI Discover ไปยังผู้ใช้วงกว้างและอุปกรณ์อื่นนอกจากทีวีหรือไม่ และจะมีผลต่อเวลารับชมจริงมากแค่ไหน
