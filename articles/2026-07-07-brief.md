## 1. JADEPUFFER แรนซัมแวร์ตัวแรกที่ AI agent ลงมือทำเองทั้งกระบวนการ

Sysdig เปิดเผยรายงานที่ TechCrunch นำมาขยายความว่าพบปฏิบัติการแรนซัมแวร์ JADEPUFFER กรณีแรกที่ AI agent โจมตีครบวงจรด้วยตัวเอง ตั้งแต่เจาะช่องโหว่ CVE-2025-3248 ใน Langflow ขโมยข้อมูลรับรอง เคลื่อนย้ายไปเซิร์ฟเวอร์ MySQL ด้วย JWT ปลอม เข้ารหัสข้อมูล 1,342 รายการ ไปจนเขียนจดหมายเรียกค่าไถ่เอง โดยมนุษย์เพียงตั้งเป้าหมายและเตรียมโครงสร้างพื้นฐาน

จุดที่น่ากังวลคือความเร็วในการปรับตัว ตอนล็อกอินล้มเหลว AI ใช้เวลาเพียง 31 วินาทีแก้ปัญหาเองจนสำเร็จ และยิง payload กว่า 600 ชุดตลอดปฏิบัติการ สะท้อนว่าทักษะเจาะระบบที่เคยต้องใช้แฮกเกอร์มากประสบการณ์ตอนนี้ agent ทำแทนได้เกือบหมด ทีมความปลอดภัยองค์กรจึงต้องเร่งปิดช่องโหว่ที่รู้จักและมอนิเตอร์พฤติกรรมผิดปกติของ agent จริงจัง เพราะต้นทุนโจมตีแบบนี้ถูกลงเรื่อยๆ

**จับตา:** ติดตามว่าจะมีเหยื่อรายอื่นที่โดนปฏิบัติการลักษณะเดียวกันตามมาอีกหรือไม่

## 2. Reddit ใช้ LLM ปราบสแปมที่เกิดจาก LLM เอง ลดการมองเห็นสแปมได้ 20%

TechCrunch รายงานว่า Reddit เริ่มใช้ LLM ตรวจจับพฤติกรรมปลอมที่ประสานงานกันแนบเนียน ซึ่งระบบเดิมเคยพลาดไป บริษัทระบุว่าตั้งแต่เดือนมกราคมลดการมองเห็นสแปมของผู้ใช้ลงได้ถึง 20% ความน่าสนใจคือความย้อนแย้งในตัวเอง เพราะสแปมที่ระบาดหนักก็มาจากใครๆ ใช้ LLM สร้างเนื้อหาปลอมได้ง่ายและถูกลง

เหตุการณ์นี้ตอกย้ำว่ายุคนี้แพลตฟอร์มโซเชียลต้องใช้ไฟสู้ไฟ เพราะสแปมที่ขับเคลื่อนด้วย AI มีปริมาณและความซับซ้อนเกินกฎเกณฑ์ตายตัวจะรับมือไหว สำหรับทีม trust and safety นี่คือกรณีศึกษาว่า LLM-based moderation ไม่ใช่ทางเลือกแต่เป็นความจำเป็นที่แพลตฟอร์มอื่นต้องเดินตามในไม่ช้า

**จับตา:** ติดตามว่า Reddit จะเปิดรายละเอียดระบบตรวจจับนี้เพิ่มหรือให้แพลตฟอร์มอื่นใช้ด้วยหรือไม่

## 3. ตั้งคำถามข้อเสนอแบ่งหุ้น OpenAI มูลค่า 300 ดอลลาร์ต่อครัวเรือนสหรัฐฯ

MIT Technology Review รายงานว่า Sam Altman กำลังพูดคุยกับ Trump เรื่องมอบหุ้น OpenAI 5% ให้รัฐบาลสหรัฐฯ จากมูลค่าบริษัท 852,000 ล้านดอลลาร์ คิดเป็นราว 42,600 ล้านดอลลาร์ หากแบ่งเท่ากันให้ครัวเรือนอเมริกันราว 133 ล้านครัวเรือน จะตกครัวเรือนละ 300 ดอลลาร์ แนวคิดนี้ต่อยอดจากที่ Altman พูดมาตลอด 5 ปีว่าชาวอเมริกันควรได้ส่วนแบ่งความมั่งคั่งจาก AI

เบื้องหลังข้อเสนอมีเหตุผลสองด้าน คือ AI เรียนรู้จากงานสร้างสรรค์ของมนุษย์โดยบริษัทแทบไม่เคยจ่ายค่าตอบแทนเจ้าของงาน และการแบ่งหุ้นอาจช่วยรองรับความกังวลเรื่องตลาดแรงงานที่จะพังทลายจาก AI แต่ผู้เขียนตั้งข้อสังเกตว่าหลายปีที่ผ่านมาข้อเสนอนี้ยังเป็นเรื่องเล่ามากกว่านโยบายจริง นี่คือสัญญาณว่าการถกเถียงเรื่องกระจายผลประโยชน์จาก AI กำลังเข้าสู่เวทีการเมืองระดับชาติจริงจังขึ้น

**จับตา:** ติดตามว่าข้อเสนอแบ่งหุ้น 5% นี้จะถูกแปลงเป็นนโยบายที่ชัดเจนเมื่อใด

## 4. CEO ของ Vercel ชี้ยุคนี้องค์กรเริ่มแยกโมเดล AI ออกจากตัว agent อย่างเป็นระบบ

TechCrunch สัมภาษณ์ Guillermo Rauch ซีอีโอ Vercel ซึ่งเผยว่า deploy บนแพลตฟอร์มถึง 6 ล้านครั้งต่อวัน ครึ่งหนึ่งเกิดจาก coding agent และมีโทเคนกว่า 1 ล้านล้านโทเคนต่อวันไหลผ่าน AI gateway Rauch ระบุว่าลูกค้าเข้าใจสถาปัตยกรรมชัดเจนขึ้นว่าโมเดล, harness, sandbox และ gateway เป็นชิ้นส่วนแยกจากกันได้ ต่างจากปีก่อนที่หลายองค์กรผูกกับแล็บเดียว

Vercel เปิดตัว Eve เฟรมเวิร์กโอเพนซอร์สที่เขียนคำสั่งและทักษะของ agent เป็นภาษาธรรมชาติแล้ว compile เป็นบริการที่รันจริงบน Vercel Functions ควบคู่กับ Vercel Sandbox ที่ควบคุมว่าข้อมูลใดเข้าออกได้บ้าง ป้องกันความเสี่ยงที่ IDE อย่าง Devin หรือ Cursor อาจดึงโค้ดทั้งระบบไปเทรนโดยไม่ตั้งใจ ทีมวิศวกรรมที่วางสถาปัตยกรรม agent ระดับ production ควรออกแบบให้สลับโมเดลได้อิสระตั้งแต่ต้น

**จับตา:** ติดตามว่า Eve framework จะถูกใช้จริงนอกอีโคซิสเต็มของ Vercel มากน้อยเพียงใด

## 5. Hugging Face อัปเดต Kernels เพิ่ม trusted publisher และ code signing สกัดมัลแวร์แฝงในโมเดล

Hugging Face เผยแพร่บล็อกอัปเดตใหญ่ของโปรเจกต์ Kernels ระบบมาตรฐานสำหรับแพ็กเกจและแจกจ่าย custom kernel บน Hub โดยตั้งแต่นี้ไปแพ็กเกจ kernels จะโหลดเฉพาะ kernel จาก trusted publisher เป็นค่าเริ่มต้น หากต้องการโหลดจากผู้เผยแพร่ที่ยังไม่ได้รับความไว้วางใจ ต้องเปิดผ่านอาร์กิวเมนต์ trust_remote_code เอง

ฟีเจอร์สำคัญกว่านั้นคือ code signing ที่ใช้ Sigstore's cosign เซ็นด้วยคีย์ชั่วคราวหมดอายุเร็ว ป้องกันกรณีบัญชี publisher ที่น่าเชื่อถือถูกแฮ็กแล้วใช้อัปโหลด kernel อันตราย พร้อมเครื่องมือ verify-signature ตรวจลายเซ็นได้เอง สะท้อนว่าช่องโหว่ supply chain ในระบบนิเวศโอเพนซอร์ส AI กลายเป็นเป้าโจมตีจริงจัง ไม่ใช่แค่ความเสี่ยงทฤษฎี ทีม ML engineering ที่พึ่งพา Hub เป็นแหล่งโมเดลควรอัปเดตและตรวจนโยบายความน่าเชื่อถือของ publisher ที่ใช้อยู่โดยเร็ว

**จับตา:** ติดตามว่ามาตรการ trusted publisher นี้จะกลายเป็นมาตรฐานที่แพลตฟอร์มอื่นใช้ตามหรือไม่
