## 1. กูเกิลปรับโครงสร้างผู้นำทีม AI ครั้งใหญ่ Jeff Dean ลาออกหลังทำงาน 27 ปี ไปตั้งบริษัทใหม่

Blognone รายงานเมื่อ 5 สิงหาคม 2569 ว่ากูเกิลประกาศปรับโครงสร้างผู้นำทีมพัฒนา AI ครั้งใหญ่ โดยเลื่อนตำแหน่ง Koray Kavukcuoglu ขึ้นเป็นรองประธานอาวุโสของ Google DeepMind ดูแลการพัฒนาโมเดล Gemini แทน ขณะที่ Demis Hassabis ขยับไปเป็นประธานของ DeepMind และ Chief Scientist ของ Alphabet มุ่งเน้นงานวิจัย AGI ส่วน Jeff Dean พนักงานคนที่ 30 ของกูเกิล ผู้ร่วมออกแบบ MapReduce, BigTable, Spanner และ TensorFlow ประกาศลาออกหลังทำงานมา 27 ปี เพื่อร่วมกับ Sanjay Ghemawat ตั้งบริษัท Discovery Loop มุ่งใช้ AI เร่งงานวิจัยวิทยาศาสตร์

ความเคลื่อนไหวนี้สะท้อนการปรับทัพครั้งสำคัญของกูเกิลในสมรภูมิ AI ที่แข่งขันดุเดือดขึ้นทุกวัน โดยดึงผู้บริหารสายเทคนิคขึ้นคุมทีมโดยตรงเพื่อเร่งพัฒนา Gemini ให้ทันคู่แข่งอย่าง OpenAI และ Anthropic ขณะเดียวกันการที่นักวิจัยระดับตำนานอย่าง Dean เลือกออกไปตั้งบริษัทเองแทนอยู่ในองค์กรใหญ่ ตอกย้ำแนวโน้มที่บุคลากรชั้นนำด้าน AI มีทางเลือกเปิดบริษัทเองได้ง่ายขึ้นด้วยเงินทุนจากนักลงทุน สำหรับองค์กรที่ใช้ Gemini การเปลี่ยนผู้นำทีมอาจหมายถึงทิศทางผลิตภัณฑ์ที่ชัดขึ้นในระยะสั้น แต่ก็เสี่ยงที่จังหวะพัฒนาโมเดลจะสะดุดช่วงเปลี่ยนผ่าน

**จับตา:** ทิศทางผลิตภัณฑ์ของ Discovery Loop บริษัทใหม่ของ Jeff Dean จะเน้นใช้ AI เร่งงานวิจัยวิทยาศาสตร์ให้เป็นรูปธรรมอย่างไร

ที่มา: [Blognone](https://www.blognone.com/node/151301)

## 2. Anthropic ตั้งทีมออกแบบชิป AI ของตัวเอง เดินเกมคุมต้นทุนโครงสร้างพื้นฐานระยะยาว

TechCrunch รายงานเมื่อ 5 สิงหาคม 2569 ว่า Anthropic กำลังตั้งทีมออกแบบชิป AI ของตัวเอง หรือ "custom silicon team" หลัง Business Insider รายงานข่าวนี้เป็นรายแรก และ Anthropic ยืนยันกับ TechCrunch ในเวลาต่อมา บริษัทระบุจะออกแบบฮาร์ดแวร์และโมเดลควบคู่กันเพื่อให้ Claude ทำงานเร็วและมีประสิทธิภาพมากขึ้น ก่อนหน้านี้เคยหารือเรื่องชิปกำหนดเองกับซัมซุงมาแล้วเมื่อเดือนกรกฎาคม และเพิ่งเซ็นดีลคอมพิวต์มูลค่ามหาศาลกับ Volta, AWS, Google และ Nvidia ต่อเนื่อง

การขยับเข้าสู่การออกแบบชิปเองสะท้อนว่า Anthropic เดินตามรอย OpenAI ที่เปิดตัวชิป Jalapeño ร่วมกับ Broadcom สำหรับงาน inference ไปแล้วเมื่อเดือนมิถุนายน เพราะพึ่งพาชิปจากผู้ผลิตภายนอกอย่างเดียวเริ่มมีต้นทุนสูงและเสี่ยงขาดแคลนกำลังผลิตในช่วงความต้องการ Claude โตเร็ว การออกแบบฮาร์ดแวร์เองช่วยปรับสถาปัตยกรรมให้เข้ากับโมเดลตรงจุดกว่าและลดต้นทุนระยะยาว แม้ต้องใช้เงินและเวลาอีกหลายปีกว่าจะเห็นผล นี่คือสัญญาณว่าบริษัทกำลังวางรากฐานระยะยาวรองรับการเติบโต ไม่ใช่แค่แก้ปัญหาระยะสั้นด้วยการซื้อกำลังประมวลผลเพิ่ม

**จับตา:** ทีมออกแบบชิปของ Anthropic จะเปิดตัวต้นแบบฮาร์ดแวร์ชุดแรกเมื่อใด และจะจับมือผู้ผลิตชิปรายใดเป็นพันธมิตรหลัก

ที่มา: [TechCrunch](https://techcrunch.com/2026/08/05/anthropic-is-hiring-an-ai-chip-design-team/)

## 3. Meta เปิดตัว Muse Code เอเจนต์ AI เขียนโค้ดสำหรับโปรเจกต์ขนาดใหญ่ ท้าชน Claude Code และ Codex

TechCrunch และ VentureBeat รายงานตรงกันเมื่อ 5 สิงหาคม 2569 ว่า Meta เปิดตัว Muse Code เครื่องมือ AI เขียนโค้ดแบบมัลติเอเจนต์ที่ทำงานผ่านเทอร์มินัล ควบคู่กับการอัปเดตโมเดล Muse Spark เป็นเวอร์ชัน 1.2 ขณะนี้เปิดให้ทดลองใช้แบบเบต้า Muse Code ถูกออกแบบมาให้รับมือโค้ดเบสขนาดใหญ่และซับซ้อนโดยเฉพาะ ทั้งวางแผนแก้ไข เขียนโค้ดจริง ไปจนถึงตรวจสอบผลลัพธ์ในระบบระดับองค์กร

การเปิดตัวครั้งนี้ทำให้ Meta ก้าวเข้าสู่สมรภูมิเครื่องมือ AI ช่วยเขียนโค้ด ท้าชนตรงกับ Claude Code ของ Anthropic และ Codex ของ OpenAI จุดขายสำคัญคือทำงานกับโค้ดเบสขนาดใหญ่ระดับองค์กรได้ทั้งระบบ ไม่ใช่แค่ช่วยเขียนโค้ดทีละไฟล์เหมือนก่อน ตอบโจทย์ทีมที่ดูแลระบบเก่าขนาดใหญ่ นักพัฒนาจึงมีตัวเลือก coding agent มากขึ้นและราคาแข่งขันดุเดือดขึ้น แต่ยังต้องรอดูว่าจะแม่นยำพอสำหรับงานระดับ production หรือไม่

**จับตา:** ผลทดสอบใช้งานจริงของ Muse Code ในโค้ดเบสระดับองค์กรจะเทียบกับ Claude Code และ Codex ได้ใกล้เคียงแค่ไหน

ที่มา: [TechCrunch](https://techcrunch.com/2026/08/05/meta-launches-muse-code-an-ai-agent-for-large-code-bases/)

## 4. Hark เปิดตัว Handoff เอเจนต์ AI ใช้เบราว์เซอร์แทนมนุษย์ สั่งอาหาร จองร้าน จองตั๋วได้เอง

TechCrunch และ VentureBeat รายงานเมื่อ 5 สิงหาคม 2569 ว่า Hark สตาร์ทอัพของ Brett Adcock ผู้ก่อตั้ง Figure AI เปิดตัว Handoff เอเจนต์ AI ที่ใช้เบราว์เซอร์แทนผู้ใช้ได้จริง โดยอ่านโครงสร้างหน้าเว็บและข้อมูลภาพเพื่อกดปุ่มหรือกรอกข้อมูล รองรับเว็บไซต์ที่ไม่มี API เช่น Target, Walmart, OpenTable และ LinkedIn Hark เพิ่งระดมทุน Series A ไป 700 ล้านดอลลาร์เมื่อเดือนพฤษภาคม

จุดต่างของ Handoff คือทำงานกับเว็บไซต์ที่ไม่มี API ได้ ต่างจากเอเจนต์ส่วนใหญ่ที่ต้องพึ่ง API เฉพาะทาง ใช้งานได้กว้างกว่าในชีวิตประจำวันจริง ทั้งสั่งอาหาร จองตั๋ว จองร้าน หรือคืนสินค้า และอ้างว่าเร็วและถูกกว่าคู่แข่งอย่าง GPT-5.5 หรือ Claude Opus 4.8 นี่คือก้าวที่ทำให้ AI agent ใกล้เคียงผู้ช่วยส่วนตัวมากขึ้น แต่ยังต้องพิสูจน์ความปลอดภัยข้อมูลผู้ใช้และความแม่นยำเมื่อเจอเว็บซับซ้อน

**จับตา:** Hark จะเปิด Handoff เต็มรูปแบบตามแผนปลายฤดูร้อนนี้หรือไม่ และความปลอดภัยข้อมูลผู้ใช้จะเป็นอย่างไร

ที่มา: [TechCrunch](https://techcrunch.com/2026/08/05/hark-previews-its-browser-use-agent-for-completing-tasks/)
