## 1. OpenAI เปิด ChatGPT Wallet ให้ AI Agent ช้อปและจ่ายเงินแทนผู้ใช้ โดยต้องยืนยันด้วยไบโอเมตริกทุกครั้ง

OpenAI เปิดตัวฟีเจอร์ Wallet ที่ให้ agent ของตัวเองชื่อ dots ช่วยตัดสินใจว่าจะซื้ออะไร แล้วชำระเงินแทนผู้ใช้ได้จนจบ ระยะแรกเปิดให้สมาชิก ChatGPT Pro ในสหรัฐฯ จำนวนจำกัด อายุ 18 ปีขึ้นไป ที่ใช้บัตร Visa, Mastercard หรือ American Express ที่ออกในสหรัฐฯ ผู้ใช้จะเห็นรายการสินค้า ยอดรวม และบัตรที่จะใช้ก่อน checkout ทุกครั้ง และต้องอนุมัติด้วย Face ID หรือลายนิ้วมือ ซึ่งจะสร้างบันทึกธุรกรรมไว้ด้วย

นี่คือการขยับจาก agent ที่ "แนะนำ" ไปสู่ agent ที่ "ลงมือ" กับเงินจริง โดยออกแบบให้มนุษย์ยังเป็นคนกดอนุมัติขั้นสุดท้าย ซึ่งช่วยลดความเสี่ยงจากการที่โมเดลเข้าใจคำสั่งผิดหรือโดน prompt injection จากหน้าเว็บร้านค้า ฝั่งธุรกิจยังต้องพิสูจน์ว่าผู้ใช้อยากให้ AI ซื้อของแทนจริงแค่ไหน เพราะ DoorDash และ Uber รายงานว่าออร์เดอร์ผ่าน agent ยังน้อย ขณะที่ Muse ของ Meta ที่มีผู้ใช้เกิน 10 ล้านคนพบว่าการช้อปเป็นกิจกรรมอันดับต้นๆ

**จับตา:** ร้านค้าออนไลน์จะปรับหน้าเว็บและระบบชำระเงินให้ agent ใช้งานได้ง่ายขึ้น หรือจะบล็อก agent แบบที่สายการบินบางรายทำ

## 2. งานวิจัยชี้โมเดล open-weight ชั้นนำของจีนเทรนบนชิป Nvidia Blackwell ที่ถูกห้ามส่งออก

งานวิจัยชิ้นใหม่อ้างว่าโมเดล open-weight ชั้นนำที่พัฒนาโดยบริษัทจีนถูกเทรนบนชิป Nvidia ที่รัฐบาลสหรัฐฯ ห้ามส่งไปจีน โดยแล็บ frontier ของจีนดูจะเข้าถึง GPU Blackwell ได้อย่างกว้างขวาง ข่าวนี้ออกมาในสัปดาห์เดียวกับที่ Jensen Huang ลาออกจากซีอีโอ Nvidia หลังยอมรับความสัมพันธ์กับ Alice Huang ผู้บริหารของ Megaspeed บริษัทที่ถูกพัวพันกับการลักลอบนำชิป Nvidia เข้าจีน ปัจจุบัน Blackwell ห้ามส่งออกไปจีนเด็ดขาด ส่วน H200 ที่อ่อนกว่าส่งได้ภายใต้เงื่อนไข

ประเด็นนี้สั่นคลอนสมมติฐานหลักของนโยบาย export control ว่าการคุมฮาร์ดแวร์จะช่วยรักษาช่องว่างความสามารถด้าน AI ระหว่างสหรัฐฯ กับจีนได้ หากชิปรุ่นท็อปหลุดไปได้จริง ความได้เปรียบเชิงนโยบายก็แคบกว่าที่คิด สำหรับ Nvidia ความเสี่ยงทางกฎหมายระดับองค์กรอาจหนักกว่าเรื่องส่วนตัวของอดีตซีอีโอ ส่วน developer ที่ใช้โมเดล open-weight จากจีนอาจต้องเผชิญคำถามเรื่อง compliance หากหน่วยงานกำกับเริ่มมองที่มาของการเทรนโมเดล

**จับตา:** ผลการสอบสวนของสภาคองเกรส และมาตรการตรวจสอบตำแหน่งชิปที่อาจถูกผลักดันให้เป็นข้อบังคับ

## 3. LangChain ระดมทุน Series C 300 ล้านดอลลาร์ มูลค่าพุ่ง 3 พันล้าน ชูจุดขาย "ไม่ล็อกโมเดล"

LangChain สตาร์ทอัพด้านการจัดการ AI agent ระดมทุน Series C 300 ล้านดอลลาร์ ที่มูลค่า 3 พันล้านดอลลาร์ นำโดย CapitalG ร่วมด้วย GIC ของสิงคโปร์, DFJ Growth, IVP และ Sapphire Ventures มูลค่าเพิ่มขึ้นกว่าเท่าตัวจาก 1.25 พันล้านดอลลาร์เมื่อราวหนึ่งปีก่อน บริษัทเริ่มจากโปรเจกต์ open source ปี 2022 ที่ช่วย LLM ยุคแรกค้นเว็บ เรียก API และคุยกับฐานข้อมูล ก่อนหันมาโฟกัสการจัดการ agent ผ่านซอฟต์แวร์ LangSmith

เรื่องที่น่าสนใจคือ LangChain รอดจากการที่แล็บใหญ่ทำ harness ของตัวเองได้ดีจนงานเดิมของมันแทบไม่จำเป็น ด้วยการย้ายไปขายชั้น "ควบคุมและดูแล agent" ที่เป็นกลางต่อผู้ให้บริการ สำหรับองค์กรที่กลัวถูกผูกติดกับคลาวด์หรือโมเดลเจ้าเดียว แนวคิด "เป็นเจ้าของ intelligence เอง" ฟังดูน่าดึงดูด แต่ตลาดนี้มีคู่แข่งจำนวนมากที่ขายจุดเด่นคล้ายกัน ความได้เปรียบระยะยาวจึงขึ้นกับว่า LangSmith คุมพฤติกรรม agent ได้ดีและใช้ง่ายจริงตามที่อ้างหรือไม่

**จับตา:** ทีมที่ใช้ agent หลายโมเดลควรลองประเมิน LangSmith เทียบกับเครื่องมือของคลาวด์ที่ใช้อยู่ในแง่การย้ายผู้ให้บริการโมเดล

## 4. llama.cpp ออกไลบรารีเวอร์ชัน 1.0.0 ประกาศใช้ semantic versioning เพื่อความเสถียรของระบบนิเวศ AI แบบ local

ทีม ggml-org ประกาศออกไลบรารี llama.cpp และ ggml เวอร์ชัน 1.0.0 หลังพัฒนามาราว 3.5 ปี llama.cpp คือเครื่องมือที่ทำให้รัน LLM แบบ multimodal ได้บนฮาร์ดแวร์หลากหลาย ตั้งแต่เครื่องผู้ใช้ทั่วไปจนถึงเซิร์ฟเวอร์องค์กร ผ่าน quantization, backend ที่ปรับแต่งแล้ว และโค้ด C/C++ ที่พกพาได้ ทีมระบุว่าเมื่อแอปปลายทางพึ่งพาโปรเจกต์มากขึ้น API ที่ยืดหยุ่นแต่เสถียรจึงสำคัญที่สุด

ไฮไลต์คือต่อจากนี้ทุกโปรเจกต์ของ ggml-org จะใช้ semantic versioning และจะเพิ่มเลขเวอร์ชันหลักเมื่อ API หรือ ABI ไม่เข้ากันกับของเดิม ฟังดูเป็นเรื่องเทคนิคเล็กๆ แต่สำหรับแอปและเครื่องมือจำนวนมากที่สร้างบน llama.cpp นี่หมายถึงการอัปเกรดที่คาดเดาได้และพังน้อยลง สะท้อนว่า AI แบบรันบนเครื่องตัวเองกำลังโตจากงานทดลองไปเป็นโครงสร้างพื้นฐานจริง ซึ่งสำคัญกับผลิตภัณฑ์ที่ให้ความสำคัญกับความเป็นส่วนตัว

**จับตา:** developer ที่ผูก llama.cpp ไว้ในแอปควร pin เวอร์ชันหลักให้ชัดและอ่านกติกา semver ใหม่ก่อนอัปเกรดครั้งถัดไป

## 5. มหิดลเปิดใช้ ChatGPT Edu ทุกวิทยาเขต เป็นมหาวิทยาลัยแรกในไทยที่ใช้ทั้งองค์กร

มหาวิทยาลัยมหิดลร่วมกับ OpenAI ประกาศเปิดใช้ ChatGPT Edu ให้อาจารย์ นักศึกษา และนักวิจัยครอบคลุมทุกวิทยาเขต เมื่อ 10 พฤศจิกายน 2569 ในงาน Mahidol x OpenAI Symposium ถือเป็นสถาบันอุดมศึกษาแห่งแรกของไทยที่ใช้ทั่วทั้งมหาวิทยาลัย ChatGPT Edu มีระบบคุ้มครองข้อมูลระดับองค์กร ข้อมูลงานวิจัยของสถาบันจะไม่ถูกนำไปเทรนโมเดล รองรับ Custom GPTs และมีโควตาข้อความสูงกว่าเวอร์ชันทั่วไป

การเลือกใช้เวอร์ชันสำหรับสถาบันแทนปล่อยให้ต่างคนต่างใช้บัญชีส่วนตัว ช่วยแก้ปัญหาเรื่องข้อมูลวิจัยและข้อมูลด้านสุขภาพรั่วไหล ซึ่งสำคัญมากกับมหาวิทยาลัยที่มีงานการแพทย์และสาธารณสุขเป็นหลักอย่างมหิดล OpenAI ระบุว่าผู้ใช้รายสัปดาห์ในไทยกลุ่มใหญ่สุดอายุ 18–24 ปี และใช้เพื่อการเรียนรู้เป็นหลัก ความท้าทายต่อไปคือการออกแบบการเรียนการสอนและการประเมินผลให้ AI ช่วยเสริมทักษะ มากกว่าทำงานแทนนักศึกษา

**จับตา:** มหาวิทยาลัยไทยแห่งอื่นจะตามมาหรือไม่ และมหิดลจะวางแนวทางการใช้ AI ในงานวิจัยทางการแพทย์อย่างไร
