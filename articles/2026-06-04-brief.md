## 1. NVIDIA เปิดตัว Nemotron 3 Ultra — โมเดล Open AI ใหญ่ที่สุดในสหรัฐฯ พร้อมดาวน์โหลดบน Hugging Face วันนี้

NVIDIA เปิดตัว Nemotron 3 Ultra โมเดล Open Weights ที่ใหญ่ที่สุดที่สหรัฐฯ เคยสร้าง ด้วยพารามิเตอร์ทั้งหมด 550 พันล้านตัว ให้ดาวน์โหลดบน Hugging Face ได้แล้ววันนี้ (4 มิ.ย.) ตัวโมเดลใช้สถาปัตยกรรม Mixture-of-Experts ที่ประมวลผลได้มากกว่า 300 โทเคนต่อวินาทีในราคาถูกกว่าคู่แข่ง 30% ทำลายสถิติโมเดล Open ของสหรัฐฯ บน AI Analysis Intelligence Index ด้วยคะแนนสูงสุดที่ 48 นับเป็นการประกาศตัวของ NVIDIA ในสมรภูมิ AI Model อย่างเป็นทางการ ไม่ใช่แค่ผู้ผลิตชิป นอกจากนี้ยังประกาศ Nemotron Coalition ร่วมกับ 8 แล็บชั้นนำรวมถึง Mistral และ Perplexity เพื่อพัฒนา Nemotron 4 บน DGX Cloud ซึ่งอาจเปลี่ยนภูมิทัศน์ตลาด Open AI Model อย่างสิ้นเชิงในปีนี้

## 2. Perplexity AI เปิดตัว Hybrid Local-Cloud Inference ที่ Computex — AI ตัดสินใจเองว่างานไหนควรอยู่บนเครื่อง งานไหนส่งขึ้น Cloud

Perplexity AI เปิดตัวระบบ Hybrid Local-Cloud Inference Orchestrator ที่งาน Computex 2026 ในไทเปร่วมกับ Intel CEO Lip-Bu Tan โดยระบบนี้ตัดสินใจแบบ Real-time ว่า Task ใดควรประมวลผลบนอุปกรณ์ผู้ใช้ และ Task ใดควรส่งขึ้น Cloud โดยอัตโนมัติ ระบบจะขอการอนุญาตผู้ใช้เสมอก่อนส่งข้อมูลออนไลน์ ซึ่งตอบโจทย์ความกังวลด้าน Data Governance ขององค์กร ฟีเจอร์นี้จะพร้อมใช้ใน Perplexity Computer สำหรับ Windows ในเดือนกรกฎาคม นี่คือก้าวที่เปลี่ยนกรอบคิดการ Deploy AI จาก "เลือกอย่างใดอย่างหนึ่ง" เป็น "ระบบฉลาดพอที่จะตัดสินใจเอง" หากแนวคิดนี้แพร่หลาย อาจเป็นมาตรฐานใหม่ที่ทำให้องค์กรสามารถใช้ Frontier Model ได้โดยไม่ต้องยอมรับความเสี่ยงด้านความเป็นส่วนตัวของข้อมูล

## 3. Snowflake แก้ปัญหา AI Agent ให้คำตอบผิดด้วยความมั่นใจ — เปิดตัว Context Layer 2 ชั้นในงาน Snowflake Summit 26

ปัญหาใหญ่ที่สุดของ AI Agent ในองค์กรขณะนี้คือการให้คำตอบผิดด้วยความมั่นใจสูง เพราะ Agent ขาดบริบทที่ถูกต้องของธุรกิจ Snowflake ตอบโจทย์นี้ในงาน Snowflake Summit 26 (1-4 มิ.ย.) ที่ซานฟรานซิสโก ด้วยการเปิดตัว Horizon Context และ Cortex Sense ระบบ Context Layer 2 ชั้นที่ให้ Agent ทุกตัวในองค์กรมองเห็น Business Logic เดียวกัน Horizon Context ดึง Metadata จากเครื่องมือทั่วทั้งองค์กร ในขณะที่ Cortex Sense สร้างบริบทจากข้อมูลและพฤติกรรมการใช้งานจริงโดยอัตโนมัติ หากได้รับการยอมรับในวงกว้าง สิ่งนี้อาจกลายเป็น Infrastructure Layer สำคัญที่ทุกองค์กรต้องมีก่อนการ Deploy AI Agent เพื่อให้ตัดสินใจบนข้อมูลที่ถูกต้องและน่าเชื่อถือ

## 4. Coralogix ระดมทุน 200 ล้านดอลลาร์ — เดิมพันว่า AI Agent จะต้องการ Monitoring Layer เป็นของตัวเอง

เมื่อ AI Agent กระจายตัวเข้าสู่ระบบองค์กรมากขึ้น การตรวจสอบและควบคุมพฤติกรรมของ Agent กลายเป็นโจทย์เร่งด่วน Coralogix บริษัท AI Observability ระดมทุน Series F มูลค่า 200 ล้านดอลลาร์ ส่งมูลค่าบริษัทแตะ 1.6 พันล้านดอลลาร์ บริษัทกำลังสร้าง Monitoring Layer เฉพาะสำหรับ AI Agent Workflow ที่ช่วยให้ทีม IT เห็นว่า Agent กำลังทำอะไร ทำไม และผลลัพธ์เป็นอย่างไรแบบ Real-time การระดมทุนครั้งนี้สะท้อนว่าตลาด AIOps กำลังขยายตัวอย่างรวดเร็ว และ AI Observability กำลังกลายเป็นหมวดธุรกิจอิสระที่มีมูลค่าสูง เทียบได้กับการเติบโตของ DevOps และ Security Monitoring ในทศวรรษที่ผ่านมา ซึ่งปัจจุบันกลายเป็นอุตสาหกรรมมูลค่าหลายหมื่นล้านดอลลาร์แล้ว
