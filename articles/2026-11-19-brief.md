## 1. Google DeepMind เปิดตัว Gemini 4 Neon โมเดลระดับแนวหน้าที่เน้นความเร็วในการทำงานจบทั้งกระบวน

Google DeepMind เปิดตัว Gemini 4 Neon โมเดลที่วางตำแหน่งว่าให้ความฉลาดระดับแนวหน้าพร้อมความเร็วในการทำงานให้จบตั้งแต่ต้นจนปลาย ทั้งงานวิศวกรรมซอฟต์แวร์ งานความรู้ และงานวิทยาศาสตร์ บริษัทระบุว่า Neon ได้คะแนน 61 บน Artificial Analysis Intelligence Index ที่ระดับการคิด xhigh อยู่อันดับ 3 รองจากโมเดลที่ใหญ่และช้ากว่า อยู่อันดับ 2 บน Vals Index และอันดับ 2 ด้าน steerability บน Agent Arena Index ราคาอยู่ที่ 3 ดอลลาร์ต่อล้านโทเคนขาเข้า 15 ดอลลาร์ต่อล้านโทเคนขาออก พร้อม context window 1 ล้านโทเคน

จุดที่น่าสนใจคือ Google เลือกขายความ "ใช้งานด้วยง่าย" ควบคู่กับคะแนนดิบ ทั้งการปรับตัวเมื่อผู้ใช้แก้คำสั่งกลางงาน และอัตราการแต่งข้อมูลที่บริษัทอ้างว่าต่ำที่สุดเท่าที่เคยวัดในการทดสอบภายใน ซึ่งสำคัญมากกับงาน agent ที่ต้องรันหลายขั้นตอน ส่วนราคาแคชอินพุตที่ลดถึง 95% (0.15 ดอลลาร์) เหมาะกับงานที่ส่ง context ยาวซ้ำๆ อย่าง coding agent อย่างไรก็ดี ตัวเลขด้าน fabrication มาจากการทดสอบของ Google เอง จึงควรรอผลวัดอิสระประกอบ

**จับตา:** ลองเทียบต้นทุนต่องานจริงของ Neon กับโมเดลที่ใช้อยู่ โดยเฉพาะงานที่ใช้ประโยชน์จากแคชอินพุตได้มาก

## 2. OpenAI อัปเดต GPT-6.2 Astra และ Sol ทำงานซับซ้อนได้ดีขึ้นด้วยโทเคนที่น้อยลงมาก

OpenAI ปล่อย GPT-6.2 Astra โมเดลขั้นสูง และ GPT-6.2 Sol โมเดลระดับกลาง โดยชูจุดเด่นเรื่องทำงานซับซ้อนด้วยโทเคนที่น้อยลง ผลทดสอบ Agents' Last Exam ระบุว่า Astra ทำคะแนนสูงกว่า GPT-6 Astra 5.2 จุดโดยใช้โทเคนไม่ถึงหนึ่งในสาม ส่วน Sol ทำคะแนนดีกว่า GPT-6.1 Sol ด้วยโทเคนราวหนึ่งในห้า ทั้งสองรุ่นใช้ได้แล้วใน ChatGPT Work และ Codex สำหรับลูกค้า Plus, Pro, Enterprise และ Edu ราคา API ของ Astra อยู่ที่ 8/40 ดอลลาร์ต่อล้านโทเคนขาเข้า/ขาออก ส่วน Sol คงราคาเดิมที่ 2/10 ดอลลาร์

ประเด็นสำคัญคือการแข่งขันเริ่มย้ายจาก "ใครเก่งกว่า" ไปสู่ "ใครทำงานเดียวกันได้ถูกกว่า" สำหรับทีมที่ใช้ agent หนักๆ ค่าใช้จ่ายจริงขึ้นกับจำนวนโทเคนที่โมเดลใช้คิดและตอบ มากกว่าราคาต่อโทเคนอย่างเดียว การลดโทเคนลงหลายเท่าจึงอาจลดบิลได้มากกว่าที่ตารางราคาบอก ข้อควรระวังคือตัวเลขเหล่านี้มาจาก benchmark ที่ OpenAI เลือกเอง และงานจริงแต่ละประเภทอาจได้ผลไม่เท่ากัน

**จับตา:** วัดจำนวนโทเคนต่องานของ GPT-6.2 กับ workload ของตัวเองก่อนตัดสินใจย้าย เพราะนี่คือตัวเลขที่ OpenAI ใช้เป็นจุดขายหลัก

## 3. Google พบคนร้ายใช้ AI แกะแพตช์ความปลอดภัยแล้วสร้างโค้ดเจาะระบบเองโดยไม่มีมนุษย์คุม

รายงาน AI Threat Tracker ฉบับล่าสุดของ Google Threat Intelligence Group (GTIG) พบว่าคนร้ายเริ่มใช้เฟรมเวิร์ก AI ที่ทำงานได้เอง คอยสแกนอัปเดตซอฟต์แวร์อย่างต่อเนื่อง หาว่าแพตช์แต่ละตัวอุดช่องโหว่ตรงไหนด้วยเทคนิค Patch Diffing แล้วสร้างโค้ดโจมตีขึ้นมาเองเพื่อเล่นงานระบบที่ยังไม่อัปเดต GTIG ระบุว่านี่เป็นครั้งแรกที่ทีมพบการใช้เฟรมเวิร์กที่ขับเคลื่อนด้วย LLM ค้นหาและเจาะช่องโหว่แบบอัตโนมัติเต็มรูปแบบ และประเมินว่าภัยจาก AI มาถึงจุดเปลี่ยนสำคัญแล้ว

ผลที่ตามมาคือช่วงเวลาปลอดภัยระหว่างวันที่แพตช์ออกกับวันที่องค์กรติดตั้งกำลังหดสั้นลงอย่างมาก เพราะแพตช์เองกลายเป็นแผนที่ชี้จุดอ่อนให้เครื่องที่ไม่ต้องพักผ่อน ช่องโหว่แบบ N-day ที่เคยถือว่าพอรอรอบอัปเดตได้จึงอันตรายขึ้น Google เสนอแนวทาง AI Threat Defense ที่ใช้ AI หาและแก้ช่องโหว่ก่อน แต่ต้องจำไว้ว่าเป็นรายงานจากผู้ขายโซลูชันความปลอดภัยเอง สำหรับทีมไอที บทเรียนที่ทำได้ทันทีคือเร่งรอบการติดตั้งแพตช์และจัดลำดับระบบที่เปิดสู่อินเทอร์เน็ตก่อน

**จับตา:** ทบทวนระยะเวลาเฉลี่ยตั้งแต่แพตช์ออกจนติดตั้งเสร็จในองค์กร เพราะตัวเลขนี้กำลังกลายเป็นตัวชี้วัดความเสี่ยงหลัก

## 4. Citibank แก้เงื่อนไขบริการ ลูกค้าที่ให้ AI agent เข้าบัญชีต้องรับผิดชอบเองแม้ถูกแฮก

Citibank ธนาคารพาณิชย์ใหญ่อันดับสามของสหรัฐฯ แก้ไขเงื่อนไขการใช้บริการสัปดาห์นี้ ระบุว่าลูกค้าที่ใช้เครื่องมือ AI ของบุคคลที่สามจัดการการเงินส่วนตัวต้องรับผิดชอบเองหากเกิดปัญหา แม้จะถูกแฮกก็ตาม โดยธนาคารจะไม่รับผิดชอบการย้อนธุรกรรมที่ผู้ช่วยอัตโนมัติทำ ไม่ว่าตั้งใจหรือไม่ โฆษกของ Citi ระบุว่าต้องการให้ลูกค้าเข้าใจความเสี่ยงของการแชร์รหัสผ่านธนาคารหรือการอนุญาตให้เครื่องมือเหล่านี้เข้าถึงบัญชี TechCrunch รายงานว่ามีธนาคารหลายแห่งเริ่มมีท่าทีเดียวกัน

ข่าวนี้ชี้ช่องว่างสำคัญของ agent ที่ทำธุรกรรมแทนคน เทคโนโลยีไปเร็วกว่ากรอบความรับผิดทางกฎหมาย เมื่อธนาคารผลักความเสี่ยงให้ผู้ใช้ ความน่าสนใจของ agent ด้านการเงินจะลดลงทันที เว้นแต่ผู้ให้บริการ agent จะยอมรับผิดชอบเองหรือมีวิธีเชื่อมต่อที่ธนาคารรับรอง สำหรับนักพัฒนา นี่เป็นสัญญาณว่าการเข้าบัญชีด้วยรหัสผ่านผู้ใช้ตรงๆ กำลังถูกต่อต้าน และระบบที่ใช้สิทธิ์จำกัดพร้อมการยืนยันแต่ละรายการจะได้เปรียบ

**จับตา:** ดูว่าธนาคารจะเปิด API สำหรับ agent ที่มีสิทธิ์จำกัดและรับรองความรับผิดชัดเจนหรือไม่ และธนาคารไทยจะมีท่าทีอย่างไร

## 5. Anthropic เปิดเผยสัดส่วนหุ้นก่อน IPO: Amazon และ Google จะถือรวมเกือบ 30%

Anthropic เปิดเผยรายละเอียดข้อตกลงลงทุนกับผู้ให้บริการคลาวด์รายใหญ่ก่อนเข้าตลาดหุ้น โดย Amazon จะถือหุ้นราว 14.7% และรวมกับ Google จะถือเกือบ 30% Amazon ได้ตั๋วสัญญาใช้เงินที่แปลงเป็นหุ้นได้จากการลงทุนในปี 2023 และ 2024 ที่ราคาแปลงราว 2.09 หรือ 5.05 ดอลลาร์ต่อหุ้น และเลือกแปลงบางส่วนเป็นหุ้นชนิดพิเศษที่ไม่มีสิทธิ์ออกเสียง ขณะที่ยังเก็บตั๋วมูลค่าหลายพันล้านดอลลาร์ไว้ ซึ่งหากแปลงทั้งหมดจะถือหุ้นได้มากกว่านี้

โครงสร้างนี้สะท้อนว่าการแข่งขัน AI ยุคนี้ผูกกับผู้ให้บริการคลาวด์อย่างแน่นแฟ้น แล็บโมเดลต้องพึ่ง compute มหาศาล ขณะที่ผู้ให้บริการคลาวด์ได้ทั้งรายได้และหุ้นที่มูลค่าพุ่ง การที่ Amazon ใช้หุ้นไม่มีสิทธิ์ออกเสียงช่วยลดข้อกังวลเรื่องการครอบงำการบริหาร แต่ตั๋วที่ยังไม่แปลงหมายถึงสัดส่วนที่อาจเปลี่ยนในอนาคต สำหรับลูกค้าองค์กรที่ใช้ Claude ผ่าน AWS หรือ Google Cloud ความสัมพันธ์นี้น่าจะทำให้การเข้าถึงโมเดลผ่านสองคลาวด์นี้มั่นคงต่อไป

**จับตา:** ติดตามวันซื้อขายวันแรกของ Anthropic และว่า Amazon จะแปลงตั๋วที่เหลือเมื่อใด ซึ่งจะเปลี่ยนสัดส่วนผู้ถือหุ้นอีกครั้ง
