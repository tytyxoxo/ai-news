## 1. Microsoft เปิดตัว Surface RTX Spark Dev Box — รันโมเดล AI 120 พันล้านพารามิเตอร์บนเครื่อง Office ได้ทันที

Microsoft ร่วมกับ Nvidia ประกาศเปิดตัว Surface RTX Spark Dev Box คอมพิวเตอร์ขนาดกะทัดรัดที่ออกแบบมาเพื่อรัน AI โมเดลขนาดใหญ่โดยไม่พึ่งพา Cloud เลย ตัวเครื่องขับเคลื่อนด้วยชิป RTX Spark สถาปัตยกรรม Blackwell ของ Nvidia พร้อม Unified Memory ถึง 128 GB และประสิทธิภาพการคำนวณ AI ที่ 1 Petaflop ทำให้นักพัฒนาสามารถโหลดและรันโมเดลที่มีพารามิเตอร์กว่า 120 พันล้านตัวได้โดยไม่ส่ง API call ไปยัง Cloud แม้แต่ครั้งเดียว นี่เป็นก้าวสำคัญที่เปลี่ยนการพัฒนา AI จากการพึ่งพา Data Center ราคาแพงมาสู่การประมวลผลบนอุปกรณ์ส่วนตัว ทำให้ต้นทุนและความเป็นส่วนตัวของข้อมูลดีขึ้นอย่างมีนัยสำคัญ คาดว่าจะวางจำหน่ายปลายปีนี้ผ่าน Microsoft.com

## 2. Microsoft เปิดตัว Scout — AI Assistant ที่จำชื่อคุณ เรียนรู้สไตล์การทำงาน และทำงานแทนคุณตลอดเวลา

งาน Microsoft Build 2026 เปิดตัว Scout ผู้ช่วย AI สร้างบนแพลตฟอร์ม OpenClaw ซึ่งต่างจาก Chatbot ทั่วไปตรงที่มี "ตัวตน" ถาวร ผู้ใช้สามารถตั้งชื่อ Scout ของตัวเองและสั่งให้เรียนรู้งานซ้ำ ๆ ที่ต้องการให้ทำโดยอัตโนมัติ พร้อมทำงานร่วมกับแอปต่าง ๆ ใน Microsoft 365 ได้อย่างราบรื่น Scout ถูกออกแบบให้เป็น "เพื่อนร่วมงาน" ที่รู้จักบุคลิกและความต้องการของผู้ใช้ ไม่ใช่แค่เครื่องมือที่เรียกใช้เป็นครั้งคราว แนวคิดนี้สะท้อนทิศทางใหม่ของ AI Agent ที่เน้นความต่อเนื่องและความสัมพันธ์ระยะยาวระหว่างคนกับ AI และอาจเปลี่ยนรูปแบบการทำงานในองค์กรอย่างถาวรในอนาคตอันใกล้

## 3. Microsoft IQ และ Rayfin — ทางออกเพื่อแก้ปัญหา AI Agents สร้าง Data Silos ขึ้นมาเอง

ปัญหาใหญ่ของ Enterprise AI ในปัจจุบันคือ AI Agent แต่ละตัวมักสร้างฐานข้อมูลและแอปพลิเคชันแยกกัน ทำให้เกิด Data Silo กระจัดกระจาย Microsoft ตอบโจทย์นี้ด้วยการเปิดตัว Microsoft IQ ระบบ Intelligence แบบ Unified ที่เพิ่มบริบทใหม่ 3 ด้าน ได้แก่ วิธีการทำงานขององค์กร คลังความรู้ขององค์กร และสัญญาณโลกแบบ Real-time ควบคู่กับ Rayfin เครื่องมือ Open-source SDK/CLI ที่บังคับให้ Agent ส่งข้อมูลมารวมที่ Microsoft Fabric เป็น Governed Backend แทนการสร้าง Silo ใหม่ ทั้งสองชิ้นส่วนนี้ทำงานร่วมกันเพื่อให้ AI ในองค์กรมองเห็นบริบทเดียวกันทั้งหมด แก้ปัญหาความขัดแย้งของข้อมูลที่กำลังกลายเป็นอุปสรรคหลักของการขยาย AI ในระดับองค์กร

## 4. Microsoft เปิด Agent Control Specification — มาตรฐาน Open Source ควบคุมพฤติกรรม AI Agent

คำถามที่ว่า "ใครควบคุม AI Agent ได้" กลายเป็นประเด็นเร่งด่วนเมื่อองค์กรนำ Agent มาใช้งานจริงในระดับกว้าง Microsoft ตอบโจทย์นี้ในงาน Build 2026 ด้วยการเปิดตัว Agent Control Specification (ACS) มาตรฐาน Open Source ที่ให้นักพัฒนากำหนดได้อย่างละเอียดว่า AI Agent ของตนมีสิทธิ์ทำอะไรได้บ้าง เปรียบเหมือนการออกแบบ "รั้ว" ที่ชัดเจนรอบพฤติกรรมของ Agent แทนการหวังว่า AI จะรู้จักขอบเขตเอง เนื่องจาก ACS เป็น Open Source จึงสามารถนำไปปรับใช้ได้บนทุก Platform และมีโอกาสสูงที่จะกลายเป็นมาตรฐานอุตสาหกรรม ซึ่งจะส่งผลให้ความน่าเชื่อถือและความปลอดภัยของ AI Agent ในวงกว้างดีขึ้นอย่างมีนัยสำคัญ

ที่มา: TechCrunch

## 5. Microsoft ASSERT — ให้ AI เขียน Test Case ทดสอบ AI ด้วยประโยคภาษาอังกฤษธรรมดา

การทดสอบว่า AI Application ทำงานถูกต้องหรือไม่เป็นโจทย์ที่ยากมาก เพราะพฤติกรรม AI มักไม่แน่นอนและยากต่อการเขียน Test แบบดั้งเดิม Microsoft จึงเปิดตัว ASSERT (Adaptive Spec-driven Scoring for Evaluation and Regression Testing) เครื่องมือ Open Source ที่ใช้ AI แปลงคำอธิบายพฤติกรรมในภาษาธรรมดา เช่น "ห้ามให้ข้อมูลเท็จ" หรือ "ต้องตอบสุภาพเสมอ" ให้กลายเป็น Test Suite ที่วัดผลได้จริงโดยอัตโนมัติ ช่วยให้ทีม AI ไม่ต้องเขียน Test Case ทีละ Case นับร้อย แนวทางนี้จะเป็นก้าวสำคัญในการรักษาคุณภาพและความปลอดภัยของระบบ AI ในองค์กรอย่างต่อเนื่อง และอาจกลายเป็นมาตรฐานสำหรับ AI Quality Assurance ในอนาคต

ที่มา: TechCrunch
