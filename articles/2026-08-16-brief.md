## 1. Qwen ของ Alibaba ทะลุ 3 พันล้านดาวน์โหลด แซง Meta-Google ขึ้นเบอร์ 1 โมเดลโอเพนซอร์สโลก

Bloomberg รายงานเมื่อวันที่ 15 สิงหาคม 2569 ว่าตระกูลโมเดล AI แบบโอเพนเวท "Qwen" ของ Alibaba มียอดดาวน์โหลดทั่วโลกทะลุ 3 พันล้านครั้งในช่วง 6 เดือนที่ผ่านมา อ้างอิงข้อมูลจาก Hugging Face แซงหน้า Google และ Meta ขึ้นเป็นตระกูลโมเดล AI ที่มีการดาวน์โหลดมากที่สุดในโลก Alibaba เปิดซอร์สโมเดล Qwen ไปแล้วกว่า 460 ตัว จนเกิดโมเดลลูกที่พัฒนาต่อยอดกว่า 300,000 ตัวทั่วโลก ขณะที่โมเดลของ Google มียอดดาวน์โหลดราว 418 ล้านครั้ง และ Meta อยู่ที่ 227 ล้านครั้งในปีเดียวกัน

ตัวเลขนี้สะท้อนว่าศูนย์กลางอำนาจของวงการ AI โอเพนซอร์สกำลังเอียงไปทางจีนอย่างชัดเจน ด้วยกลยุทธ์เปิดเผยน้ำหนักโมเดลฟรีที่ทำให้นักพัฒนาทั่วโลกหันมาใช้และต่อยอด Qwen ในปริมาณมหาศาล แม้คุณภาพเชิงเบนช์มาร์กอาจยังไม่แซงหน้าโมเดลปิดของค่ายตะวันตกในทุกด้าน สำหรับนักพัฒนา นี่หมายถึงตัวเลือกโมเดลคุณภาพสูงที่ปรับแต่งได้อิสระและรันเองได้โดยไม่ต้องพึ่ง API ราคาแพง ส่วนธุรกิจที่มองหาทางลดต้นทุนและลดการผูกติดผู้ให้บริการรายเดียว อาจเริ่มเห็นเส้นทางที่ชัดขึ้นในการใช้โครงสร้างพื้นฐาน AI โอเพนซอร์สจากจีนแทนโมเดลปิดราคาแพง

**จับตา:** ยอดดาวน์โหลดมหาศาลของ Qwen จะแปลงเป็นรายได้จริงให้ธุรกิจคลาวด์ของ Alibaba ได้มากน้อยแค่ไหน

ที่มา: [Bloomberg](https://www.bloomberg.com/news/articles/2026-08-15/alibaba-ai-models-hit-3-billion-downloads-passing-meta-google)

## 2. SpaceX ยืนยันปิดดีลควบรวม Cursor อย่างเป็นทางการ ชูจุดขายเข้าถึงฝูง GPU ใหญ่ที่สุดในโลก

TechCrunch รายงานเมื่อวันที่ 15 สิงหาคม 2569 ว่า Cursor สตาร์ทอัพ AI เขียนโค้ดชื่อดัง กลายเป็นส่วนหนึ่งของ SpaceX อย่างเป็นทางการแล้ว หลังปิดดีลควบรวมที่ตกลงกันไว้ตั้งแต่เดือนเมษายน ซึ่งให้สิทธิ์ SpaceX ซื้อกิจการ Cursor ในมูลค่า 6 หมื่นล้านดอลลาร์ ข่าวนี้เป็นการยืนยันอย่างเป็นทางการ หลังก่อนหน้านี้หนึ่งวันมีรายงานผ่านเอกสารกำกับดูแลว่าดีลปิดไปแล้ว โดย Cursor ระบุว่าการเข้าร่วมกับ SpaceX จะทำให้เข้าถึง "ฝูง GPU ที่ใหญ่ที่สุดในโลก"

ดีลนี้ตอกย้ำว่าอีลอน มัสก์ กำลังผนวกรวมทุกชั้นของ AI ไว้ในมือเดียว ตั้งแต่โครงสร้างพื้นฐานคอมพิวเตอร์ผ่าน xAI ไปจนถึงเครื่องมือที่นักพัฒนาใช้งานจริงอย่าง Cursor ต่างจากคู่แข่งอย่าง Anthropic และ OpenAI ที่ยังพึ่งพาพันธมิตรคลาวด์ภายนอก การเข้าถึง GPU ฝูงใหญ่โดยตรงอาจทำให้ผู้ใช้ Cursor ได้อานิสงส์เรื่องความเร็วตอบสนองและข้อจำกัดการใช้งานที่ผ่อนคลายลง แต่ผู้ใช้เดิมที่คุ้นเคยกับการเลือกโมเดลจากหลายค่ายก็เริ่มกังวลว่า Cursor อาจถูกดึงเข้าสู่ระบบนิเวศของมัสก์มากขึ้น จนเอนเอียงไปทาง Grok ของ xAI เป็นค่าเริ่มต้นในอนาคต

**จับตา:** Cursor จะยังคงรองรับโมเดลจากค่ายอื่นอย่าง Claude และ GPT ในสัดส่วนเท่าเดิมหรือไม่ หลังผนวกเข้ากับ SpaceX เต็มตัว

ที่มา: [TechCrunch](https://techcrunch.com/2026/08/15/spacex-officially-closes-its-cursor-acquisition/)

## 3. Anthropic แจกแจงกลไก watermark ข้อความของ Claude ทำงานอย่างไรเมื่อถูกแก้ไขหรือใช้เขียนโค้ด

TechCrunch รายงานเมื่อวันที่ 15 สิงหาคม 2569 ว่า Anthropic ให้รายละเอียดเพิ่มเติมเกี่ยวกับระบบ watermark ข้อความที่ Claude สร้างขึ้น โดยใช้แนวทาง SynthID-Text ที่ทีม Google DeepMind เคยเผยแพร่ไว้เมื่อปี 2024 พร้อมประกาศแผนเปิด API สำหรับตรวจจับ watermark ระบบนี้เปลี่ยนแค่แหล่งที่มาของการสุ่มเลือกคำโดยไม่กระทบคุณภาพเนื้อหา ทำให้ข้อความที่มีและไม่มี watermark แยกไม่ออกด้วยสายตาคน แต่ตรวจสอบได้ด้วยกุญแจเฉพาะ

ประเด็นที่น่าสนใจคือ Anthropic อธิบายว่าความเข้มของ watermark ขึ้นกับว่ามนุษย์แก้ไขข้อความที่ Claude เขียนมากแค่ไหน ถ้าแก้ไขเบาๆ ร่องรอย watermark แทบไม่หายไป แต่ถ้าเขียนใหม่ทั้งหมดก็จะลบออกได้ ส่วนโค้ดโปรแกรมจะมี watermark น้อยกว่าข้อความทั่วไปเพราะโมเดลต้องเขียนโค้ดให้ทำงานได้จริง มีที่ว่างให้เลือกคำน้อยกว่า มาตรการนี้เกิดขึ้นเพื่อให้สอดคล้องกับ EU AI Act ที่บังคับให้ผู้ให้บริการ AI ต้องมีระบบระบุตัวตนเนื้อหาที่สร้างจาก AI ได้ ซึ่งอาจกลายเป็นมาตรฐานที่ค่ายอื่นต้องทำตามในอนาคต

**จับตา:** Anthropic จะเปิด API ตรวจจับ watermark ให้บุคคลภายนอกใช้งานจริงเมื่อไร และแม่นยำแค่ไหนในทางปฏิบัติ
