## 1. Prometheus ของ Jeff Bezos ระดมทุน $12 พันล้าน มุ่งสร้าง "วิศวกร AI" สำหรับโลกจริง

Jeff Bezos ผันตัวเป็นผู้ประกอบการด้าน AI อย่างเต็มตัวผ่านสตาร์ทอัป Prometheus ที่เพิ่งระดมทุนได้ $12 พันล้านดอลลาร์ที่มูลค่า $41 พันล้านดอลลาร์ โดยร่วมก่อตั้งกับ Vik Bajaj อดีตผู้ร่วมก่อตั้ง Verily หน่วยวิทยาศาสตร์เพื่อชีวิตของ Google เป้าหมายคือสร้าง "วิศวกรปัญญาประดิษฐ์ขั้นทั่วไป" (Artificial General Engineer) ซอฟต์แวร์ที่สามารถออกแบบและผลิตระบบทางกายภาพที่ซับซ้อน ตั้งแต่เครื่องยนต์เจ็ทไปจนถึงสารประกอบทางยา ผู้สนับสนุนรวมถึง JPMorgan Chase, Goldman Sachs และ BlackRock เม็ดเงินนี้เป็นรอบที่สองต่อจากรอบ $6.2 พันล้านดอลลาร์แรก สะท้อนว่านักลงทุนสถาบันชั้นนำยังคงเชื่อมั่นใน AI ที่เชื่อมกับโลกกายภาพอย่างแน่วแน่

## 2. เปิดโปงการโจมตีซัพพลายเชน AI 4 ครั้งใน 50 วัน จากระบบนิเวศ OpenAI, Anthropic และ Meta

เหตุการณ์โจมตีซัพพลายเชนระบบ AI ครั้งใหญ่ 4 ครั้งใน 50 วันเผยให้เห็นช่องโหว่ที่ทีมรักษาความปลอดภัยยังไม่ครอบคลุม เหตุการณ์สำคัญได้แก่ การปลอมปน LiteLLM proxy gateway ยอดนิยมที่ถูกดาวน์โหลดเกือบ 47,000 ครั้งก่อนถูกตรวจจับ หนอนคอมพิวเตอร์ Mini Shai-Hulud ที่ฝังตัวใน npm packages ของ TanStack ใน 6 นาที และซอร์สโค้ด Claude Code ที่หลุดออกมาเมื่อ Anthropic ส่ง source map ขนาด 59.8 MB ไปกับ npm package โดยไม่ตั้งใจ เหตุการณ์เหล่านี้ชี้ให้เห็นว่า pipeline การ release โมเดล AI ยังขาดมาตรการรักษาความปลอดภัยที่ทีม red team ยังไม่ได้ตรวจสอบอย่างจริงจัง

## 3. วิศวกร Meta Applied AI เดือด ยูนิตใหม่ 6,500 คนถูกเปรียบเป็น "ค่ายกักกัน"

รายงานจาก TechCrunch เปิดเผยสถานการณ์น่าเป็นห่วงภายใน Meta Applied AI ยูนิตที่เพิ่งก่อตั้งได้เพียง 3 เดือน โดยมีวิศวกรและผู้จัดการผลิตภัณฑ์กว่า 6,500 คนที่เผชิญกับบรรยากาศทำงานตึงเครียดอย่างหนัก มีเหตุการณ์บุกรุกการนำเสนอสดของพนักงานพร้อมคำพูดรุนแรงออกอากาศ สะท้อนความไม่พอใจที่สะสมมานาน แม้ Meta จะลงทุนด้าน AI อย่างมหาศาลตลอดปี 2026 แต่การบริหารทีมขนาดใหญ่ที่ต้องเร่งผลลัพธ์ในวัฒนธรรมองค์กรใหม่ยังคงเป็นความท้าทายสำคัญ ซึ่งอาจส่งผลต่อขีดความสามารถในการแข่งขันด้าน AI ของ Meta หากบริษัทไม่รีบแก้ไขปัญหาเชิงโครงสร้างนี้

## 4. Microsoft เปิดตัว SkillOpt โอเพนซอร์ส อัปเกรด AI Agent Skills อัตโนมัติโดยไม่แตะ Model Weights

Microsoft เปิดตัว SkillOpt โปรเจกต์โอเพนซอร์ส MIT license ที่นำแนวคิด deep learning มาประยุกต์กับการพัฒนา AI agent skills โดยไม่ต้องแก้ไข model weights เดิมเลย แทนที่จะให้นักพัฒนาปรับ prompt แบบ "เดาเอา" SkillOpt จะ optimize ไฟล์คำสั่ง .md ของ agent โดยอัตโนมัติผ่านการตรวจสอบทางคณิตศาสตร์ แสดงให้เห็นว่าเพิ่มความแม่นยำได้อย่างมีนัยสำคัญบน benchmark ต่าง ๆ รวมถึงบนโมเดลอย่าง GPT-5.5 และ Qwen นวัตกรรมนี้เป็นก้าวสำคัญที่ช่วยให้ AI agent พัฒนาตัวเองได้อย่างเป็นระบบ ลดภาระนักพัฒนาจากกระบวนการปรับแต่งด้วยมือที่ใช้เวลาและมีความคลาดเคลื่อนสูง

## 5. Google ฟ้องปฏิบัติการอาชญากรรมไซเบอร์จีน ใช้ AI ส่ง SMS หลอกลวงกว่า 2.5 ล้านข้อความ

Google ยื่นฟ้องปฏิบัติการอาชญากรรมไซเบอร์ที่อ้างว่าดำเนินการโดยกลุ่มจีนชื่อ Outsider Enterprise ในข้อหาใช้ AI สร้างข้อความหลอกลวงในระดับมหาศาล กลุ่มนี้สร้างเว็บไซต์ปลอม 9,000 แห่ง โดเมนหลอกลวงกว่า 1 ล้านโดเมน และส่ง SMS หลอกลวง 2.5 ล้านข้อความในเพียง 2 สัปดาห์ไปยังผู้ใช้ Android โดยแอบอ้างเป็น Google เพื่อขโมยรหัสผ่านและข้อมูลบัตรเครดิต ความเสียหายประเมินไว้ที่หลายล้านดอลลาร์จากเหยื่อหลายแสนคน คดีนี้ถือเป็นบรรทัดฐานสำคัญในการต่อสู้กับการใช้ AI เพื่อก่อการฉ้อโกงอย่างเป็นอุตสาหกรรม และอาจเปิดทางให้บริษัทเทคโนโลยีอื่นดำเนินคดีในลักษณะเดียวกันในอนาคต

ที่มา: TechCrunch
