## 1. OpenAI ปิดเงินทุนรอบแรก 11,000 ล้านดอลลาร์ ที่มูลค่า 1.25 ล้านล้านดอลลาร์

Bloomberg รายงานว่า OpenAI ได้รับเงินทุนก้อนแรกราว 11,000 ล้านดอลลาร์แล้วในวันศุกร์ โดยเป็นส่วนหนึ่งของการระดมทุนที่ประเมินมูลค่าบริษัทไว้ที่ 1.25 ล้านล้านดอลลาร์ ส่วนที่เหลือคาดว่าจะเสร็จในอีกไม่กี่สัปดาห์ และยอดรวมอาจสูงถึงราว 20,000 ล้านดอลลาร์ ซึ่งต่ำกว่าเป้าหมาย 30,000 ล้านดอลลาร์ที่เคยมีรายงานเมื่อปลายเดือนกันยายน ตามข้อมูลของ TechCrunch ที่อ้างแหล่งข่าวของ Bloomberg

ตัวเลขที่ต่ำกว่าเป้าบอกว่านักลงทุนเริ่มระมัดระวังมากขึ้น ในช่วงที่ตลาดหุ้นเทคโนโลยีเพิ่งปรับฐานแรง และมีรายงานว่าผู้สนใจหุ้น IPO ของ Anthropic ก็ประเมินมูลค่าต่ำลงจากที่เคยคาดไว้ สำหรับนักพัฒนาและธุรกิจที่พึ่งพา API ของค่ายใหญ่ ประเด็นคือเงินทุนยังไหลเข้าอยู่ แต่แรงกดดันให้พิสูจน์รายได้จะสูงขึ้น ซึ่งอาจสะท้อนในนโยบายราคาและการแข่งขันด้านบริการองค์กร ทั้งนี้ข้อมูลทั้งหมดมาจากแหล่งข่าวที่ไม่เปิดเผยชื่อ และ OpenAI ยังไม่ได้ยืนยัน

**จับตา:** ติดตามว่ารอบระดมทุนจะปิดที่ยอดรวมเท่าใดในอีกไม่กี่สัปดาห์ข้างหน้า และมูลค่า 1.25 ล้านล้านดอลลาร์จะถูกปรับหรือไม่

ที่มา: [TechCrunch](https://techcrunch.com/2026/11/06/openai-reportedly-raises-an-additional-11-billion-at-a-1-25-trillion-valuation/)

## 2. งานวิจัยชี้ โมเดล AI เปิดน้ำหนักจากจีนเจาะเครือข่ายได้เกือบเท่าโมเดลปิดชั้นนำ

Wired รายงานผลทดสอบของ Vals บริษัทวัดความสามารถ AI ซึ่งให้โมเดลต่างๆ ลงมือเจาะเครือข่ายจำลองขององค์กรที่ต้องทำหลายขั้นตอนต่อเนื่อง ผลพบว่าโมเดลแบบเปิดน้ำหนักที่ใครก็ดาวน์โหลดได้ มีความสามารถใกล้เคียงโมเดลชั้นแนวหน้าที่ถูกจำกัดการเข้าถึงอยู่ในห้องแล็บ นักวิจัยของ Vals ระบุว่าโมเดลปิดไม่ได้มีแต้มต่อด้านทักษะไซเบอร์อย่างชัดเจนอีกต่อไป

ผลนี้ท้าทายแนวคิดของห้องแล็บสหรัฐฯ ที่เปิดตัวโมเดลแบบจำกัดสิทธิ์ เช่น Claude Mythos Preview ในเดือนเมษายน โดยหวังว่าการคุมการเข้าถึงจะซื้อเวลาให้ฝ่ายป้องกัน หากความสามารถกระจายไปถึงโมเดลเปิดแล้ว ทีม security ต้องวางแผนบนสมมติฐานว่าผู้โจมตีเข้าถึงเครื่องมือระดับสูงได้ ขณะเดียวกันควรอ่านผลด้วยความระวัง เพราะเป็นการทดสอบบนเครือข่ายจำลองหนึ่งชุด ไม่ใช่สภาพแวดล้อมจริงที่หลากหลาย

**จับตา:** ดูว่านโยบายจำกัดการเข้าถึงโมเดลไซเบอร์ของห้องแล็บใหญ่จะถูกปรับ หรือมีผลทดสอบอิสระรายอื่นยืนยันข้อค้นพบนี้หรือไม่

ที่มา: [Wired](https://www.wired.com/story/free-chinese-ai-models-are-getting-scary-good-at-hacking/)

## 3. Microsoft Research เปิด PDD Kit พิสูจน์โค้ดที่เอเจนต์เขียนด้วย Verus

Microsoft Research แนะนำ PDD Kit ชุดเครื่องมือที่ช่วยแปลงเจตนาของนักพัฒนาให้เป็นข้อกำหนดเชิงรูปนัยใน Verus แล้วพิสูจน์ว่าโค้ดที่เอเจนต์เขียนตรงตามข้อกำหนดสำหรับทุกอินพุต และใช้การทดสอบแทนในส่วนที่การพิสูจน์เข้าไม่ถึง ทีมวิจัยลองใช้กับตรรกะการล็อกอินของ Pet Store ร้านค้าที่เขียนด้วย Rust ภายในโครงการ Chopin ของ GitHub Next และบอกว่าพบบั๊กที่มีอยู่เดิมด้วย

เหตุผลที่น่าสนใจคือ เมื่อเอเจนต์สร้างโค้ดจำนวนมาก การรีวิวทีละบรรทัดโดยมนุษย์ไม่สามารถขยายตามได้ และแผนงานที่เขียนไว้ก็ไม่มีอะไรบังคับให้เอเจนต์ทำตาม ส่วนเทสต์ที่เอเจนต์เขียนมักตรวจสิ่งที่มันสร้าง ไม่ใช่สิ่งที่ผู้ใช้ขอ แนวทางเชิงรูปนัยจึงเป็นทางเลือกที่ลดช่องว่างนี้ แต่ต้องยอมรับว่าการพิสูจน์ครอบคลุมเฉพาะข้อกำหนดที่เขียนไว้ หากข้อกำหนดผิดเจตนา โค้ดที่ผ่านการพิสูจน์ก็ยังผิดอยู่ดี

**จับตา:** ลองใช้กับโมดูลเล็กๆ ที่ตรรกะชัดเจนอย่างการยืนยันตัวตนหรือการคำนวณราคา แล้วดูว่าการเขียนข้อกำหนดใช้แรงมากน้อยเพียงใด

## 4. ข้อมูล Ramp ชี้ ยอดใช้จ่ายด้าน AI ของบริษัทนิ่งลง แม้ปริมาณโทเคนเพิ่ม

TechCrunch รายงานข้อมูลจาก Ramp ว่ายอดใช้จ่ายด้านโทเคนของบริษัทลูกค้าโตเพียง 1.5 เปอร์เซ็นต์ตลอดเดือนสิงหาคมถึงกันยายน เทียบกับ 42 เปอร์เซ็นต์ที่โตจากเดือนก่อนในเดือนกรกฎาคม ทั้งที่ปริมาณโทเคนที่ใช้เพิ่มขึ้น Ara Kharazian หัวหน้านักเศรษฐศาสตร์ของ Ramp ตีความว่าการแข่งขันด้านราคาและลูกค้าที่รู้จักใช้มากขึ้น อาจเป็นตัวจำกัดรายได้ของ OpenAI และ Anthropic

ประเด็นที่น่าสนใจคือ รายจ่ายส่วนใหญ่มาจากบริษัทเทคโนโลยีที่ได้เงินทุนเสี่ยงและเติบโตเร็ว หากกลุ่มนี้ชะลอพร้อมกัน ผลกระทบอาจลุกลามได้ ตามคำเตือนของ Kharazian ซึ่งเห็นสัญญาณแล้วว่ากลุ่มบริษัทที่ใช้ AI หนักที่สุดร้อยละ 1 ใช้จ่ายสะดุดเล็กน้อย สำหรับฝ่ายธุรกิจ นี่อาจหมายถึงอำนาจต่อรองด้านราคาที่ดีขึ้น แต่ข้อมูลมาจากฐานลูกค้าของ Ramp เท่านั้น จึงอาจไม่ใช่ภาพรวมของทั้งตลาด

**จับตา:** ดูตัวเลขยอดใช้จ่าย AI ของ Ramp เดือนตุลาคมและพฤศจิกายน ว่าการนิ่งนี้ต่อเนื่องหรือเป็นแค่ช่วงสั้นๆ

ที่มา: [TechCrunch](https://techcrunch.com/2026/11/06/ramp-data-shows-ai-spending-stalling-just-as-anthropic-nears-its-ipo/)

## 5. Perplexity เปิดตัว Teammates เอเจนต์ที่รับงานระยะยาวแทนการทำงานครั้งเดียว

Techsauce รายงานว่า Perplexity เปิดตัว Teammates เอเจนต์ส่วนตัวที่ออกแบบมาเพื่อดูแลงานต่อเนื่อง ตั้งแต่วางแผนและประสานงานโปรเจกต์ ปรับแผนเมื่อลำดับความสำคัญเปลี่ยน ไปจนถึงส่งผลงานกลับมาให้คนตรวจ โดยทำงานอยู่ภายใน Perplexity Computer ระบบเอเจนต์ที่ดึงโมเดลหลายตัวมาทำงานร่วมกัน เข้าถึงเครื่องมือและไฟล์ของผู้ใช้ได้ และผู้ใช้เข้าไปดูหรือชี้ทิศทางได้ตลอดทาง

เหตุผลที่ Perplexity ให้ไว้คือ แม้ Computer จะรับโปรเจกต์ซับซ้อนได้ แต่การตั้งเอเจนต์ให้ดูแลงานต่อเนื่องยังต้องวางแผนเองมาก Teammates แต่ละตัวจะประสานเซสชันกับตัวอื่นและจดจำสิ่งที่เรียนรู้ระหว่างทาง ทิศทางนี้สะท้อนว่าตลาดเอเจนต์กำลังขยับจากงานธุระครั้งเดียวอย่างจองร้านอาหาร ไปสู่การเป็นเพื่อนร่วมทีมที่ถือความรับผิดชอบยาวขึ้น แต่ยังต้องดูว่าความน่าเชื่อถือและการควบคุมสิทธิ์เข้าถึงไฟล์จะเป็นอย่างไรในการใช้งานจริง

**จับตา:** ลองมอบงานที่ซ้ำและมีขั้นตอนชัดเจน เช่น รายงานรายสัปดาห์ แล้วตรวจว่าเอเจนต์ปรับแผนและส่งงานได้ตรงเจตนาแค่ไหน
