## 1. OpenAI เปิดตัว Partner Network ลงทุน 150 ล้านดอลลาร์ มุ่งรับรอง AI Consultant 300,000 คน

OpenAI ประกาศเปิดตัว "OpenAI Partner Network" อย่างเป็นทางการ พร้อมลงทุน 150 ล้านดอลลาร์สร้างระบบนิเวศพาร์ตเนอร์ระดับองค์กรทั่วโลก โปรแกรมนี้มีโครงสร้าง 3 ระดับ ได้แก่ Select, Advanced และ Elite โดยพาร์ตเนอร์รายแรกๆ ได้แก่บริษัทที่ปรึกษาชั้นนำอย่าง McKinsey, Boston Consulting Group, Accenture และ Capgemini เป้าหมายสำคัญคือการรับรอง "AI consultant" จำนวน 300,000 คนภายในสิ้นปี 2026 เพื่อให้พร้อมช่วยองค์กรทั่วโลกวางแผน ติดตั้ง และขยายการใช้งาน AI เชิงพาณิชย์ ก้าวนี้แสดงให้เห็นว่า OpenAI กำลังแปลงตัวเองจากบริษัทเทคโนโลยีสู่บริษัทระบบนิเวศ คล้ายกับที่ Salesforce และ Microsoft เคยสร้างเศรษฐกิจพาร์ตเนอร์ขนาดใหญ่มาก่อน และอาจส่งผลให้บริษัทที่ปรึกษาหลายแห่งปรับกลยุทธ์ AI หลักของตนมาจับมือกับ OpenAI แทน

ที่มา: OpenAI

## 2. Anthropic ปรับโครงสร้าง Claude API มีผลวันนี้ — ปลดระวางโมเดล Claude 4 รุ่นเดิมและแยกระบบเรียกเก็บเงินสำหรับ Agentic AI

วันนี้ Anthropic ปรับโครงสร้าง Claude API สำคัญ 2 เรื่องพร้อมกัน เรื่องแรกคือการปลดระวางโมเดล claude-sonnet-4-20250514 และ claude-opus-4-20250514 ออกจาก API โดยให้ย้ายไปใช้ Claude Sonnet 4.6 และ Claude Opus 4.8 แทน เรื่องที่สองคือการแยกการใช้งาน "programmatic" อย่าง Agent SDK, claude -p และ Claude Code ออกจาก subscription pool หลัก โดยย้ายไปใช้ระบบ credit รายเดือนแยกต่างหาก ราคาประมาณ $20 สำหรับ Pro และ $100-200 สำหรับ Max โดย credit ไม่สะสมข้ามเดือนและไม่แบ่งกันภายในทีม การเปลี่ยนแปลงนี้สะท้อนให้เห็นว่า Anthropic เริ่มแยกตลาด "ผู้ใช้ทั่วไป" ออกจาก "นักพัฒนา AI agents" อย่างชัดเจน และวางแผนคิดเงินตามการใช้จริงมากขึ้น ซึ่งอาจส่งผลต่อต้นทุนการพัฒนา AI agentic ระยะยาว

ที่มา: Anthropic
