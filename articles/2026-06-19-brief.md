## 1. รัฐบาลสหรัฐฯ สั่ง fast-track เชื่อมต่อ AI data center เข้าโครงข่ายไฟฟ้าแห่งชาติ

หน่วยงาน FERC (Federal Energy Regulatory Commission) ออกคำสั่งเมื่อวันที่ 18 มิถุนายน ให้ผู้ดำเนินการโครงข่ายไฟฟ้า 6 แห่งทั่วสหรัฐฯ เร่งอนุมัติการเชื่อมต่อ data center และผู้ใช้ไฟฟ้าขนาดใหญ่โดยเร็ว สะท้อนว่ารัฐบาลสหรัฐฯ มองพลังงานสำหรับ AI เป็นโครงสร้างพื้นฐานเชิงยุทธศาสตร์ที่ต้องเร่งพัฒนา ผู้ดำเนินการโครงข่ายมีเวลา 30 วันในการรายงานกำลังสำรอง และ 60 วันในการทบทวนอัตราค่าไฟ นอกจากนี้ FERC ยังเปิดโอกาสให้ startup เทคโนโลยีกริดเข้าร่วม โดยให้ผู้ดำเนินการพิจารณาใช้เทคโนโลยีทางเลือก ความต้องการไฟฟ้าจาก data center คาดว่าจะเพิ่มขึ้นเกือบ 3 เท่าภายในปี 2035 ทำให้นโยบายนี้มีผลกระทบระยะยาวต่อการแข่งขัน AI ทั่วโลก

## 2. Google ยุติ Gemini CLI บังคับนักพัฒนาย้ายสู่ Antigravity CLI ที่เป็นซอฟต์แวร์ปิด

เมื่อวันที่ 18 มิถุนายน Google ได้ปิดให้บริการ Gemini CLI อย่างเป็นทางการสำหรับผู้ใช้ Pro, Ultra และฟรีทั้งหมด เครื่องมือที่เคยเปิดแบบ Apache 2.0 open-source สะสม GitHub star ถึง 100,000+ และมีชุมชนผู้พัฒนาขนาดใหญ่ถูกแทนที่ด้วย Antigravity CLI ที่เป็น closed-source Go binary โดยไม่มีซอร์สโค้ดเผยแพร่ นักพัฒนาต่างแสดงความไม่พอใจอย่างชัดเจน เนื่องจาก Antigravity CLI ยังไม่มีความสามารถเทียบเท่า Gemini CLI ณ เวลาเปิดตัว และกรณีนี้สะท้อนความเสี่ยงของการพึ่งพาเครื่องมือที่บริษัทยักษ์ใหญ่ควบคุมแบบเบ็ดเสร็จ ผู้พัฒนาที่ต้องการทางเลือก open-source จะต้องหันไปใช้ Claude Code หรือ Aider แทน

ที่มา: The Register

## 3. Anthropic เปิดสำนักงานโซลและจับมือพันธมิตรยักษ์ใหญ่เกาหลี ก่อน IPO

Anthropic ประกาศเปิดสำนักงานกรุงโซลเมื่อวันที่ 17-18 มิถุนายน นับเป็นสำนักงานแห่งที่ 3 ในภูมิภาคเอเชียแปซิฟิก ต่อจากโตเกียวและบังกาลอร์ การขยายตัวนี้มาพร้อมกับการประกาศพันธมิตรระดับแนวหน้าของเกาหลี ได้แก่ NAVER, Samsung SDS, LG CNS และ Nexon ที่จะนำ Claude มาใช้ในองค์กร รวมถึงการลงนาม MOU กับกระทรวงวิทยาศาสตร์และ ICT ของเกาหลีใต้ เพื่อความร่วมมือด้าน AI ของภาครัฐและการทดสอบความปลอดภัย การเคลื่อนไหวนี้เกิดขึ้นท่ามกลางความตึงเครียดด้านข้อจำกัดการส่งออก AI ของสหรัฐฯ และก่อนที่ Anthropic จะเข้าจดทะเบียนในตลาดหลักทรัพย์ในฤดูใบไม้ร่วงนี้ ที่มูลค่าสูงถึง 965,000 ล้านดอลลาร์

ที่มา: Anthropic

## 4. Anthropic เปิดตัว Claude Code Artifacts แปลง session โค้ดเป็น dashboard แบบ interactive สำหรับองค์กร

VentureBeat รายงานเมื่อวันที่ 18 มิถุนายน ว่า Anthropic เปิดตัวฟีเจอร์ Artifacts สำหรับ Claude Code บนแผน Team และ Enterprise โดยช่วยแปลงผลลัพธ์จาก session การเขียนโค้ดให้กลายเป็นเว็บเพจ HTML แบบ interactive และแชร์ได้แบบ real-time ผู้ใช้สามารถเชื่อมข้อมูลหลายแหล่ง สร้างกราฟและ dashboard ที่อัปเดตสดตามที่ Claude Code ทำงาน และส่งลิงก์ให้ทีมเปิดดูได้ทันที ฟีเจอร์นี้สะท้อนทิศทางของ AI ที่เปลี่ยนจากการตอบคำถามสู่การสร้างงานที่ใช้ได้จริงในระดับองค์กร และเป็นหลักฐานว่า Anthropic กำลังเร่งสร้างระบบนิเวศรอบ Claude Code ก่อนเข้าตลาดหุ้น

ที่มา: VentureBeat

## 5. UN จัดประชุมนานาชาติว่าด้วย AI ความมั่นคง และจริยธรรม ที่เจนีวา 18-19 มิถุนายน

UNIDIR (สถาบันวิจัยการลดอาวุธแห่งสหประชาชาติ) จัดการประชุม Global Conference on AI, Security and Ethics 2026 ที่ Palais des Nations นครเจนีวา ในวันที่ 18-19 มิถุนายน รวบรวมนักการทูต ผู้กำหนดนโยบาย เจ้าหน้าที่ทหาร ตัวแทนอุตสาหกรรม และองค์กรภาคประชาสังคมจากทั่วโลก เพื่อหารือผลกระทบของ AI ต่อสันติภาพและความมั่นคงระหว่างประเทศ Microsoft เป็นผู้ร่วมสนับสนุน และการประชุมครั้งนี้ยังเป็นจุดเปิดตัว UNIDIR Centre of Excellence on AI, Peace and Security อย่างเป็นทางการ เป็นสัญญาณชัดว่า AI ได้ก้าวขึ้นมาเป็นวาระด้านความมั่นคงระหว่างประเทศที่ไม่ต่างจากอาวุธนิวเคลียร์หรือไซเบอร์

ที่มา: UNIDIR
