## 1. Robinhood เปิดให้ AI Agent เทรดหุ้นได้โดยตรง — ก้าวสำคัญสู่ยุค Agentic Finance

Robinhood ประกาศฟีเจอร์ใหม่ที่อนุญาตให้ AI agent เข้าถึงและทำการซื้อขายหลักทรัพย์ในบัญชีของผู้ใช้ได้โดยตรง ผ่าน Model Context Protocol (MCP) ที่บริษัทพัฒนาขึ้น ผู้ใช้สามารถสร้างบัญชีแยกต่างหากสำหรับ AI agent พร้อมกระเป๋าเงินเฉพาะที่โหลดเงินไว้ล่วงหน้าเพื่อจำกัดความเสี่ยง โดย agent สามารถวิเคราะห์พอร์ตโฟลิโอ ระบุความเสี่ยงจากการกระจุกตัวของหุ้น และออกคำสั่งซื้อขายได้อัตโนมัติ ปัจจุบันรองรับการซื้อขายหุ้นในระยะแรก โดยมีแผนขยายไปสู่ออปชัน สกุลเงินดิจิทัล และสัญญาฟิวเจอร์ส นอกจากนี้ Robinhood ยังเปิดตัว virtual credit card สำหรับ AI agent โดยเฉพาะ ซึ่งถือเป็นก้าวสำคัญที่ทำให้ agentic finance เริ่มกลายเป็นความจริงในชีวิตประจำวัน

## 2. Anthropic เปิดตัว Claude Code Security Plugin — ตรวจจับช่องโหว่ขณะพิมพ์โค้ด

Anthropic เปิดตัวปลั๊กอินด้านความปลอดภัยสำหรับ Claude Code ที่สามารถตรวจสอบและแก้ไขช่องโหว่แบบเรียลไทม์ขณะที่นักพัฒนากำลังเขียนโค้ด ปลั๊กอินนี้ตรวจจับปัญหาสำคัญอย่าง injection flaws, unsafe deserialization และ insecure DOM APIs ก่อนที่โค้ดจะถูกส่งขึ้น pull request ช่วยลดภาระงาน code review ด้านความปลอดภัยในขั้นตอนหลัง การตรวจสอบเบื้องต้นทำงานโดยไม่เรียกใช้โมเดล AI จึงไม่เพิ่มต้นทุน และให้บริการฟรีสำหรับผู้ใช้ทุกแผน สอดคล้องกับกลยุทธ์ใหม่ของ Anthropic ในการขยาย Claude Security ออกจากขอบเขตงานวิจัยสู่เครื่องมือที่ developer ใช้งานได้จริงในสภาพแวดล้อมปกติ พร้อมกันนี้ยังมีสัญญาณว่า Claude Mythos รุ่นพิเศษด้านความปลอดภัยกำลังจะพร้อมให้บริการในเชิงพาณิชย์เร็วๆ นี้

ที่มา: Anthropic

## 3. DataGrail เผย 63.6% ของผู้ให้บริการซอฟต์แวร์ส่งข้อมูลลูกค้าให้ AI โดยไม่แจ้งล่วงหน้า

รายงาน Privacy and AI Trends Report 2026 จาก DataGrail ที่วิเคราะห์ผู้ให้บริการซอฟต์แวร์กว่า 2,400 รายพบข้อมูลที่น่าตกใจว่า 63.6% ของผู้ให้บริการที่โฆษณาความสามารถ AI อย่างเด่นชัดไม่ได้เปิดเผย third-party AI subprocessor ในเอกสารกฎหมาย ซึ่งหมายความว่าบริษัทส่วนใหญ่ที่ซื้อซอฟต์แวร์ที่มี AI อาจกำลังส่งข้อมูลลูกค้าไปยัง AI model ที่ตนเองไม่รู้จักและไม่เคยอนุมัติ รายงานระบุว่าข้อตกลง data processing ที่เคยเป็นหลักในการประเมินความน่าเชื่อถือของผู้ให้บริการ ไม่สามารถเชื่อถือได้ตามตัวหนังสืออีกต่อไป แนวโน้มนี้มีความสำคัญอย่างยิ่งต่อองค์กรที่ต้องรักษาความสอดคล้องตามกฎระเบียบ GDPR, CCPA และกฎหมายความเป็นส่วนตัวอื่นๆ

## 4. Meta เปิดตัว Meta One — AI Subscription ระดับ Premium $19.99 ต่อเดือน สำหรับผู้ใช้ทั่วไป

Meta ประกาศเปิดตัวแผนสมาชิกใหม่สำหรับ Instagram, Facebook และ WhatsApp อย่างเป็นทางการทั่วโลก โดยมีแผน Plus แยกตามแอปในราคา 2.99-3.99 ดอลลาร์ต่อเดือน พร้อมกันนี้บริษัทยังทดสอบแผน AI subscription 2 ระดับสำหรับผู้ใช้ Meta AI โดยเฉพาะ คือ Meta One Plus ($7.99/เดือน) และ Meta One Premium ($19.99/เดือน) ซึ่งระดับ Premium จะปลดล็อก "thinking mode" เชิงลึกสำหรับงานซับซ้อน พร้อมโควต้าการสร้างวิดีโอและภาพที่มากขึ้น การเปิดตัวนี้สะท้อนให้เห็นว่า Meta กำลังเดินหน้าสู่โมเดลรายได้ที่พึ่งพา AI subscription อย่างจริงจัง โดยไม่ยกเลิก Meta Verified เดิม ซึ่งอาจส่งสัญญาณให้ผู้ให้บริการ AI รายอื่นๆ พิจารณาแนวทางเดียวกัน

## 5. ผู้บริหาร Tech กำลังป่วยด้วย "AI Psychosis" — เชื่อมโยงกับการปลดพนักงานพุ่งสูง

Aaron Levie ผู้ก่อตั้ง Box ชี้ว่าผู้บริหารระดับ CEO กำลังตกอยู่ในสภาวะ "AI psychosis" คือการมองโลกผ่านแว่น AI สีชมพูโดยไม่ตระหนักถึงความซับซ้อนของการนำ AI มาใช้งานจริง บทวิเคราะห์ระบุว่าในช่วง 5 เดือนแรกของปี 2026 อุตสาหกรรมเทคโนโลยีมีการปลดพนักงานเกือบเท่ากับตลอดปี 2025 โดยบริษัทส่วนใหญ่อ้าง AI เป็นเหตุผล แม้ระบบ AI จริงๆ ยังไม่ได้ทดแทนงานเหล่านั้น ปัญหาหลักคือผู้บริหารมักอยู่ห่างจากกระบวนการทำงานจริง จึงประเมินศักยภาพ AI สูงเกินความเป็นจริง ผลที่เกิดขึ้นคือการตัดสินใจทางธุรกิจที่ผิดพลาด การลดกำลังคนโดยขาดแผนรองรับ และความไม่ไว้วางใจของพนักงานที่เพิ่มสูงขึ้นทั่วทั้งอุตสาหกรรม
