## 1. Mistral AI ประกาศรุกใหญ่ — เปลี่ยนชื่อ Le Chat เป็น Vibe พร้อมบุก Industrial AI และลงทุน Data Center 4 พันล้านยูโร

Mistral AI บริษัท AI จากฝรั่งเศสเปิดตัวการประกาศครั้งใหญ่ในงาน inaugural conference โดยเปลี่ยนชื่อผู้ช่วย AI Le Chat เป็น "Vibe" และปรับโฉมใหม่เป็น unified agent platform สำหรับองค์กรและนักพัฒนา พร้อมกันนี้บริษัทประกาศ Mistral for Industrial Engineering ระบบ AI ที่รวม LLM เข้ากับ physics simulation จากการซื้อกิจการ Emmi AI สำหรับงานวิศวกรรมอุตสาหกรรม Mistral Compute เผยแผนลงทุน 4 พันล้านยูโรในดาต้าเซ็นเตอร์ที่ฝรั่งเศสและสวีเดน มุ่งสู่ 1 GW ภายในปี 2030 ปัจจุบัน Mistral มีพนักงาน 1,000 คนและตั้งเป้ารายได้ 1 พันล้านยูโรในปีนี้ การประกาศครั้งนี้สะท้อนให้เห็นว่ายุโรปกำลังสร้างตัวเองเป็นขั้วอำนาจ AI ในระดับโลกอย่างจริงจัง โดยไม่ยอมเป็นเพียงผู้ใช้เทคโนโลยีที่พัฒนาโดยบริษัทอเมริกันอีกต่อไป

## 2. Mistral Vibe 2.0 ท้าตีเต้า GitHub Copilot — Coding Agent รุ่นใหม่รุกตลาด Enterprise ด้วยกลยุทธ์ Open-Source

Mistral AI เปิดตัว Vibe 2.0 coding agent รุ่นล่าสุดในงานเดียวกัน โดยมุ่งเป้าแข่งขันโดยตรงกับ GitHub Copilot ของ Microsoft จุดเด่นคือการ prompt ผู้ใช้ก่อนดำเนินการทุกครั้ง ลดความเสี่ยงจากการแก้โค้ดโดยไม่ตั้งใจ พร้อม slash-command skills สำหรับงาน deploy, lint และสร้าง documentation รวมถึง unified agent modes ที่ทีมงานกำหนดค่าเองได้ กลยุทธ์ open-source ของ Mistral ดึงดูดองค์กรที่ไม่ต้องการส่ง proprietary code ไปยังบุคคลที่สาม แผน Le Chat Pro ราคา 14.99 ดอลลาร์ต่อเดือนรวม Vibe CLI และ Devstral 2 ซึ่งเป็น model หลักที่ขับเคลื่อนระบบ การเคลื่อนไหวครั้งนี้อาจกลายเป็นทางเลือกสำคัญสำหรับ developer และองค์กรที่ต้องการ sovereignty เหนือโค้ดและข้อมูลของตัวเอง

## 3. Sesame เปิดตัว iOS App — AI ผู้ช่วยจากผู้ก่อตั้ง Oculus ที่คุยได้เป็นธรรมชาติเหมือนมนุษย์

Sesame สตาร์ทอัพ AI ที่ก่อตั้งโดย Brendan Iribe ผู้ร่วมก่อตั้ง Oculus เปิดตัว iOS app อย่างเป็นทางการหลังจากพัฒนากว่าหนึ่งปีในช่วง beta แอปนี้แตกต่างจาก ChatGPT ตรงที่ออกแบบให้การสนทนาไหลเป็นธรรมชาติผ่านเสียงที่ฟังดูเหมือนมนุษย์จริงๆ ฟีเจอร์ที่เพิ่มมาในเวอร์ชันนี้ได้แก่ search cards พร้อมรูปภาพ notes สำหรับบันทึกสรุป texting mode สำหรับสถานการณ์ที่พูดไม่ได้ และ incognito mode สำหรับการสนทนาส่วนตัว ที่น่าจับตามองคือบริษัทมองว่า iOS app เป็นเพียงก้าวแรก โดยมีแผนเปิดตัว AI eyewear ในปี 2027 ซึ่งชี้ให้เห็นทิศทางที่ AI จะก้าวข้ามหน้าจอสู่อุปกรณ์ wearable ที่ติดตัวผู้ใช้ตลอดเวลา

## 4. นักลงทุนล่า "Cerebras รุ่นต่อไป" — General Compute ระดมทุน $15M สำหรับ AI Inference Neocloud

หลัง Cerebras ระดมทุน IPO ได้ 5.5 พันล้านดอลลาร์และราคาหุ้นพุ่ง 108% ในวันแรก นักลงทุนเริ่มมองหา startup รุ่นต่อไปในตลาด AI compute โดยเฉพาะฝั่ง inference General Compute สตาร์ทอัพ inference neocloud ที่เน้นให้บริการคอมพิวต์ในช่วง inference ซึ่งแตกต่างจาก training ระดมทุน seed round ได้ 15 ล้านดอลลาร์ที่มูลค่า 60 ล้านดอลลาร์ นำโดย FUSE VC โดยเลือกใช้ชิปจาก SambaNova ที่ออกแบบเฉพาะสำหรับ inference แทนการสร้างชิปเอง กระแสนี้สะท้อนการเปลี่ยนแปลงสำคัญในอุตสาหกรรม AI ที่ตลาดเริ่มแยกความต้องการ training และ inference ออกจากกัน เปิดช่องให้ startup ที่เชี่ยวชาญด้าน inference speed และ cost-efficiency เติบโตได้โดยไม่ต้องแข่งกับ NVIDIA โดยตรง

## 5. ผู้ร่วมก่อตั้ง Databricks ชี้สาเหตุที่ดีล AI ระดับ Enterprise ล้มเหลว — ปัญหาไม่ได้อยู่ที่เทคโนโลยี

Arsalan Tavakoli-Shiraji ผู้ร่วมก่อตั้ง Databricks ขึ้นพูดบน AI Stage ของ TechCrunch Disrupt 2026 ชี้ว่าสาเหตุหลักที่ดีล enterprise AI ล้มเหลวไม่ใช่เรื่องเทคโนโลยี แต่เป็น "operational instability" หรือความไม่มั่นคงในการดำเนินงานที่ตามมาจากการนำ AI มาใช้ องค์กรส่วนใหญ่ไม่ได้ปฏิเสธ AI แต่ปฏิเสธความปั่นป่วนของกระบวนการทำงานที่เปลี่ยนไป คนที่ต้องเรียนรู้ใหม่ และระบบที่ต้องปรับ ผลที่เกิดขึ้นคือ pilot สำเร็จแต่แทบไม่กลายเป็น deployment จริง Databricks เป็นตัวอย่างความสำเร็จด้วยรายได้ run rate 5.4 พันล้านดอลลาร์ เติบโต 65% ต่อปี โดยมากกว่า 1.4 พันล้านมาจากผลิตภัณฑ์ AI บทเรียนสำคัญคือบริษัทที่เข้าใจ "ความเป็นจริงขององค์กร" จะอยู่รอดและสร้างรายได้ระยะยาวได้ดีกว่า

ที่มา: TechCrunch
