## 1. นักวิจัยวางกับดัก 2 ล้านจุด พบห่วงโซ่บริการ AI รั่วข้อมูลลับผู้ใช้เหมือนตะแกรง

Ars Technica รายงานการทดลองของนักวิจัยที่ฝัง "กับดักดิจิทัล" กว่า 2 ล้านจุดไว้ในคำขอที่ส่งผ่านเครือข่ายบริการ AI เพื่อดูว่าข้อมูลอ่อนไหวที่ฝากไว้จะไปจบที่ไหน ผลคือพบระบบนิเวศที่รั่วข้อมูลสำคัญเหมือนตะแกรง จุดสำคัญอยู่ที่ "AI router" หรือ "AI gateway" อย่าง OpenRouter หรือ Vercel ที่รับ prompt จำนวนมากจากแอปแล้วส่งต่อไปยัง inference engine ตามราคาหรือความเหมาะสมของงาน HD Moore ใช้ AWS access key ที่ใช้งานได้จริงแต่ผูกกับบัญชีว่าง รหัสผ่าน SSH และข้อมูลระบุตัวตนอื่นๆ เป็นเหยื่อล่อ

ประเด็นนี้ชี้ว่าความเสี่ยงของแอป AI ไม่ได้อยู่แค่ที่ผู้ให้บริการโมเดลรายใหญ่ แต่อยู่ตลอดสายส่งต่อที่ผู้ใช้มองไม่เห็น เมื่อ developer เลือกใช้ router เพื่อประหยัดต้นทุน prompt ของผู้ใช้อาจไปถึงผู้ให้บริการปลายทางที่ไม่มีใครตรวจสอบ ทีมที่สร้างแอปควรถือว่าทุกอย่างใน prompt อาจหลุดได้ และไม่ควรส่ง credential หรือข้อมูลลับเข้าไปตรงๆ ส่วนองค์กรที่ให้พนักงานวางโค้ดหรือไฟล์ config ลงแชตบอต ต้องคิดใหม่ว่าข้อมูลเหล่านั้นเดินทางผ่านใครบ้าง

**จับตา:** ตรวจสอบว่าแอปที่ใช้อยู่ส่ง prompt ผ่าน router ตัวกลางหรือไม่ และตั้งระบบกรอง secret ออกก่อนส่งถึงโมเดล

ที่มา: [Ars Technica](https://arstechnica.com/security/2026/11/a-leaky-ai-supply-chain-is-exposing-secret-user-data-at-an-alarming-rate/)

## 2. นักคณิตศาสตร์ของ Anthropic อ้างว่าพิสูจน์สมมติฐานรีมันน์ได้ด้วยความช่วยเหลือของ Claude

Levent Alpöge นักคณิตศาสตร์ของ Anthropic อ้างว่าพิสูจน์สมมติฐานรีมันน์ (Riemann Hypothesis) ได้ด้วยความช่วยเหลือของ Claude โจทย์นี้มีมาตั้งแต่ปี 1859 และเป็นหนึ่งในปัญหารางวัล Millennium Prize ที่นักคณิตศาสตร์ชั้นนำแก้ไม่ได้มาหลายทศวรรษ The Verge ระบุว่าบทพิสูจน์ยังไม่ผ่านการตรวจสอบอย่างอิสระ และ Anthropic ไม่ได้แสดงความเห็นหรือเกี่ยวข้องกับการประกาศครั้งนี้ Alpöge เขียนในเอกสารบนเว็บไซต์ของตัวเองว่าได้ส่งข้อความหา Dario Amodei ก่อนประกาศ ซึ่งตรงกับสัปดาห์ที่บริษัทเพิ่งเข้าตลาดหุ้น

ถ้าบทพิสูจน์ผ่านการตรวจสอบ นี่จะเป็นหมุดหมายใหญ่ของ AI ในคณิตศาสตร์ ต่อจากความพยายามก่อนหน้าของ OpenAI ที่ถูกวิจารณ์ว่ายังไม่สวยงามนัก แต่ต้องย้ำว่าตอนนี้ยังเป็นเพียง "คำอ้าง" ประวัติศาสตร์คณิตศาสตร์มีบทพิสูจน์รีมันน์ที่ล้มเหลวมาแล้วหลายครั้ง และงานระดับนี้มักใช้เวลานานกว่าชุมชนจะยอมรับ ในมุมการใช้งาน กรณีนี้สะท้อนรูปแบบที่ AI ทำงานร่วมกับผู้เชี่ยวชาญในงานวิจัยเชิงลึก มากกว่าการแก้โจทย์ได้เองทั้งหมด

**จับตา:** ผลการตรวจสอบจากนักคณิตศาสตร์อิสระ และการเปิดเผยว่า Claude มีบทบาทในขั้นตอนไหนของบทพิสูจน์

ที่มา: [The Verge](https://www.theverge.com/ai-artificial-intelligence/1010051/anthropic-riemann-hypothesis-millennium-prize-problem)

## 3. METR อัปเดตกราฟ "time horizon" ความสามารถ AI ยังโตแบบทวีคูณ แต่งานที่ต้องใช้วิจารณญาณยังตามหลังงานโค้ด

METR องค์กรไม่แสวงกำไรด้านการประเมิน AI ออกรายงานอัปเดตกราฟ time horizon ที่เคยถูกแชร์และตีความผิดอย่างกว้างขวาง วิธีวัดคือให้โมเดลทำชุดงานที่มนุษย์เคยทำแล้ว ให้คะแนนความยากตามเวลาที่มนุษย์ใช้ และจัดอันดับโมเดลตามความยาวของงานที่ทำสำเร็จ กราฟเดิมชี้ว่าความยาวงานที่โมเดลแนวหน้าทำได้เพิ่มเป็นเท่าตัวทุกสี่เดือน ฉบับใหม่เพิ่มงานที่มนุษย์ใช้เวลานานกว่าเดิมมากและงานปลายเปิด ผลพบว่าบางความสามารถยังโตแบบทวีคูณ แต่โมเดลยังทำงานที่ต้องใช้วิจารณญาณได้ไม่ดีเท่างานโค้ด

ข้อค้นพบนี้แตะคำถามใหญ่ว่าความก้าวหน้าในงานที่ "ตรวจคำตอบได้อัตโนมัติ" จะลามไปถึงงานที่ตรวจยากหรือไม่ เพราะเทคนิคฝึกแบบ reinforcement learning ได้ผลดีที่สุดกับงานที่มีคำตอบชัด สำหรับ developer นี่ยืนยันว่า agent เขียนโค้ดได้ยาวขึ้นเรื่อยๆ แต่งานที่ต้องตัดสินใจเชิงบริบทยังต้องมีคนคุม ส่วนผู้บริหารควรระวังการอ่านกราฟนี้เป็นตัวเลขเดียวที่บอกว่า AI แทนคนได้กี่ชั่วโมง

**จับตา:** ช่องว่างระหว่างงานที่ตรวจได้กับงานที่ต้องใช้วิจารณญาณในรายงานรอบถัดไป ว่าจะแคบลงหรือถ่างออก

## 4. OpenAI เปิดแนวทางรับมือ "adversarial distillation" การลอกความสามารถโมเดลไปใช้โดยไม่มีระบบป้องกัน

OpenAI เผยแพร่บทความอธิบายวิธีตรวจจับและสกัดกั้น adversarial distillation คือการนำผลลัพธ์จากโมเดลแนวหน้าไปฝึกโมเดลอื่นให้มีความสามารถใกล้เคียงกันโดยไม่ได้รับอนุญาต แล้วนำไปใช้โดยไม่มีระบบป้องกันเทียบเท่าต้นฉบับ ตัวอย่างที่ยกมาคือการกลั่นความสามารถด้านไซเบอร์ไปช่วยโจมตีที่โมเดลต้นฉบับจะปฏิเสธ แนวทางของ OpenAI ผสมการทดสอบเชิงโจมตี การฝึกโมเดล ตัวจำแนก (classifier) การป้องกันระดับ API และการสืบสวนความพยายามดึงความสามารถแบบประสานงาน รวมถึงเสริมการป้องกัน reasoning ของโมเดลด้วย

ประเด็นนี้สะท้อนว่าการแข่งขันด้าน AI ไม่ได้อยู่แค่ใครฝึกโมเดลเก่งกว่า แต่รวมถึงการปกป้องความสามารถที่สร้างแล้วด้วย เพราะ safeguard ที่ใส่ไว้ในโมเดลไม่มีความหมายหากถูกลอกออกไปได้ง่าย สำหรับ developer ที่ใช้ API ผลกระทบที่อาจตามมาคือการตรวจจับรูปแบบการเรียกใช้ที่เข้มขึ้น และการซ่อน reasoning บางส่วนไว้ ซึ่งอาจกระทบงานที่ต้องการความโปร่งใส ทั้งนี้เป็นข้อมูลจากฝั่ง OpenAI เอง จึงยังไม่รู้ว่าวิธีเหล่านี้ได้ผลจริงแค่ไหน

**จับตา:** ค่ายอื่นจะร่วมแชร์ข้อมูลและมาตรฐานป้องกัน distillation ตามที่ OpenAI เสนอหรือไม่ และนโยบาย API จะเข้มงวดขึ้นอย่างไร

ที่มา: [OpenAI](https://openai.com/index/combatting-adversarial-distillation)

## 5. Signal ปิดการแคปหน้าจอบน iOS และ Android เป็นค่าเริ่มต้น กัน AI ของระบบปฏิบัติการอ่านแชต

Blognone รายงานว่า Signal ประกาศมาตรการป้องกันไม่ให้ AI บนระบบปฏิบัติการสมาร์ทโฟนเข้าถึงข้อมูลแชตในแอป บน iOS จะปิดการเข้าถึงของ Siri AI และปิดการจับภาพหน้าจอในแอปทั้งหมดเป็นค่าเริ่มต้น ส่วนบน Android จะป้องกันการจับภาพหน้าจอและบล็อกการเข้าถึงของแอปผู้ช่วย AI ทั้งหมด ผู้ใช้ปิดฟีเจอร์นี้ได้แต่ Signal ไม่แนะนำ แนวทางนี้คล้ายกับที่ Signal เคยบล็อกฟีเจอร์ Recall บน Windows 11 เมื่อปีที่แล้ว

Signal ยอมรับว่ามาตรการนี้ยังไม่พอ เพราะไม่ได้บล็อกการเข้าถึงระดับไฟล์ และเรียกร้องให้ Apple กับ Google เปิดเผยรายละเอียดการทำงานของ AI บนระบบปฏิบัติการให้นักพัฒนามากขึ้น เรื่องนี้ชี้ความขัดแย้งใหม่ระหว่าง AI ที่อยากเห็นทุกอย่างบนหน้าจอเพื่อช่วยผู้ใช้ กับแอปที่สัญญาเรื่องความเป็นส่วนตัว นักพัฒนาแอปที่จัดการข้อมูลอ่อนไหว เช่น ธนาคารหรือการแพทย์ ควรเริ่มทบทวนว่าหน้าจอของตัวเองถูก AI ของระบบอ่านได้แค่ไหน

**จับตา:** Apple และ Google จะเปิดเครื่องมือให้นักพัฒนากำหนดได้ว่า AI ของระบบเข้าถึงข้อมูลในแอปได้แค่ไหนหรือไม่
