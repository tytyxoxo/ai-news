## 1. กลุ่มเทคยักษ์ใหญ่นำโดย Nvidia-Microsoft ยื่นจดหมายเปิดผนึก หนุนโมเดล AI แบบ open-weight สู้แรงกดดันจากจีน

TechCrunch รายงานเมื่อ 24 กรกฎาคม 2569 ว่ากลุ่มบริษัทเทคโนโลยีนำโดย Nvidia และ Microsoft ยื่นจดหมายเปิดผนึกถึงผู้กำหนดนโยบายสหรัฐฯ เรียกร้องให้สนับสนุนการพัฒนาโมเดล AI แบบ open-weight ต่อไป โดยมี Meta, Palantir, Hugging Face และ Mistral ร่วมลงนาม จดหมายฉบับนี้ออกมาท่ามกลางความกังวลในวอชิงตันหลังโมเดล Kimi K3 ของจีนจาก Moonshot AI แสดงศักยภาพสูงจนจุดกระแสถกเถียงว่าควรจำกัดโมเดลโอเพนซอร์สหรือไม่

จดหมายเรียกร้องให้ขยายการเข้าถึงกำลังประมวลผลแก่สตาร์ทอัพและนักวิจัย ลงทุนในชุดข้อมูลและเครื่องมือประเมินผลร่วมกัน และหลีกเลี่ยงมาตรการจำกัดโมเดลเปิดแบบเหมารวมที่อาจบั่นทอนการแข่งขันหรือผลักดันให้นวัตกรรมย้ายออกนอกสหรัฐฯ สะท้อนความกังวลว่านโยบายกีดกันที่เข้มงวดเกินไปอาจทำร้ายอีโคซิสเต็มนักพัฒนาที่พึ่งพาโมเดลโอเพนซอร์สอยู่แล้ว ขณะเดียวกันก็เป็นการปกป้องผลประโยชน์ของบริษัทที่ได้กำไรจากตลาดโมเดลเปิดกว้าง เช่น Nvidia ที่ขายชิปให้ทุกค่าย

**จับตา:** ท่าทีของทำเนียบขาวต่อข้อเรียกร้องนี้จะออกมาเป็นนโยบายที่ผ่อนปรนหรือเข้มงวดกว่าเดิม

ที่มา: [TechCrunch](https://techcrunch.com/2026/07/24/as-us-weighs-response-to-chinese-ai-industry-urges-against-broad-open-weight-restrictions/)

## 2. Midjourney ฮุบแอปโหราศาสตร์ Co-Star เดินเกมสร้างแอปสแตนด์อโลนตัวแรก

TechCrunch รายงานเมื่อ 24 กรกฎาคม 2569 ว่า Midjourney สตาร์ทอัพ AI สร้างภาพเข้าซื้อกิจการ Co-Star แอปโหราศาสตร์ยอดนิยมที่ใช้ผังดวงชะตาผสมกับการเขียนโดย AI และมนุษย์ให้คำแนะนำส่วนตัวและวิเคราะห์ความเข้ากันได้ระหว่างผู้ใช้กับเพื่อน ดีลนี้ปิดตั้งแต่ช่วงฤดูใบไม้ผลิที่ผ่านมาแต่เพิ่งเปิดเผยตอนนี้โดยไม่ระบุมูลค่า Co-Star มีผู้ใช้งานต่อเดือนราว 4.3 ล้านคน ให้ใช้ฟรีพร้อมฟีเจอร์เสริมแบบเสียเงิน

ทีมงาน Co-Star ราวสองโหลคนเข้าร่วม Midjourney ทั้งหมด ซึ่งจะช่วยให้บริษัทที่คุ้นเคยกับการทำงานผ่าน Discord bot ได้ประสบการณ์สร้างแอปสแตนด์อโลนของตัวเองเป็นครั้งแรก ดีลนี้สะท้อนว่า Midjourney กำลังขยายจากธุรกิจสร้างภาพแกนหลักสู่การเป็นบริษัทแอปสำหรับผู้บริโภคเต็มตัว อาศัยความเชี่ยวชาญของทีม Co-Star ในการออกแบบประสบการณ์ผู้ใช้ที่จับต้องได้มากกว่าเครื่องมือสร้างภาพทั่วไป

**จับตา:** แอปสแตนด์อโลนตัวแรกของ Midjourney จะเปิดตัวเมื่อใดและจะผนวกฟีเจอร์แบบ Co-Star เข้าไปด้วยหรือไม่

## 3. Meta และ Microsoft เผชิญแรงกดดันนักลงทุนเรื่องงบ AI มหาศาล ก่อนฤดูรายงานผลประกอบการ

Bloomberg รายงานเมื่อ 24 กรกฎาคม 2569 ว่า Microsoft, Meta และ Amazon กำลังเผชิญความกังวลจากนักลงทุนรอบใหม่เรื่องแผนลงทุนโครงสร้างพื้นฐาน AI ที่พึ่งพาการก่อหนี้จำนวนมาก หลัง Alphabet ปรับเพิ่มเพดานงบลงทุนปี 2569 ขึ้นอีกถึง 1.5 หมื่นล้านดอลลาร์เป็น 1.95-2.05 แสนล้านดอลลาร์ สร้างแรงกระเพื่อมไปทั่ววงการก่อนที่บริษัทเทคยักษ์ใหญ่รายอื่นจะทยอยประกาศผลประกอบการในสัปดาห์ถัดไป

ตลาดกำลังจับตาอย่างใกล้ชิดว่าการลงทุน AI มหาศาลนี้จะให้ผลตอบแทนคุ้มค่าจริงหรือไม่ ท่ามกลางบรรยากาศภูมิรัฐศาสตร์ที่ยังไม่นิ่ง โดยเฉพาะแรงกดดันจากโมเดลจีนอย่าง Kimi K3 ที่ทำให้นักลงทุนตั้งคำถามหนักขึ้นว่าความได้เปรียบด้านเทคโนโลยีของสหรัฐฯ ยังคุ้มกับเงินที่เทลงไปหรือไม่ นักลงทุนที่ถือหุ้นบริษัทเทคใหญ่ควรเตรียมรับความผันผวนของราคาหุ้นในช่วงฤดูรายงานผลประกอบการนี้

**จับตา:** ผลประกอบการของ Microsoft และ Meta ที่จะประกาศในสัปดาห์หน้าจะทำให้หุ้นร่วงซ้ำรอย Alphabet หรือไม่

ที่มา: [Bloomberg](https://www.bloomberg.com/news/articles/2026-07-24/meta-microsoft-face-renewed-unease-over-ai-spending-us-earnings-week-ahead)

## 4. OpenAI ปล่อย ChatGPT Voice บนเดสก์ท็อป สั่งงาน agent เขียนโค้ดด้วยเสียงได้เต็มรูปแบบ

TechCrunch รายงานเมื่อ 24 กรกฎาคม 2569 ว่า OpenAI เปิดให้ใช้ ChatGPT Voice บนแอปเดสก์ท็อป macOS และ Windows ขับเคลื่อนด้วยโมเดล GPT-Live ที่ฟัง-พูดพร้อมกันได้แบบ full-duplex ผู้ใช้สามารถสั่งงานและประสานงานหลาย agent ใน ChatGPT Work หรือ Codex ด้วยเสียงพูดโดยตรง พร้อมขัดจังหวะสนทนาได้ตามธรรมชาติ ใช้สิทธิ์และเครื่องมือเดียวกับโหมดที่เลือกอยู่

ในคลิปสาธิต นักพัฒนาสั่งด้วยเสียงเพียงคำสั่งเดียวให้สร้าง thread ใหม่ เปิด pull request และหาสาเหตุบั๊กจนเสร็จ สะท้อนว่า OpenAI กำลังผลักดันการเขียนโค้ดแบบ hands-free เข้าสู่ workflow จริงของนักพัฒนา ไม่ใช่แค่ฟีเจอร์สนทนาทั่วไป นี่คือก้าวต่อจาก GPT-Live ที่เปิดตัวบนมือถือและเว็บเมื่อสองสัปดาห์ก่อน ตอนนี้ขยายมาสู่เครื่องมือทำงานหลักของสายเทคอย่างเต็มรูปแบบ

**จับตา:** ฟีเจอร์นี้จะรองรับภาษาไทยและขยายไปยัง Linux เมื่อใด
