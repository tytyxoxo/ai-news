## 1. เมื่อ API Key กลายเป็นประตูลับ: นักพัฒนา Google Cloud โดนบิล Gemini หมื่นดอลลาร์โดยไม่รู้ตัว

เหตุการณ์สะเทือนวงการ AI Security ถูกเปิดเผยเมื่อนักพัฒนาหลายรายบน Google Cloud ต้องรับค่าใช้จ่ายหลักหมื่นดอลลาร์จากการเรียกใช้ Gemini API โดยไม่ได้ตั้งใจ กรณีที่โด่งดังที่สุดคือ Rod Danan ซีอีโอของ Prentus ซึ่งโดนบิลสูงถึง 10,138 ดอลลาร์ภายในเวลาเพียง 30 นาที สาเหตุอยู่ที่การที่ Google ขยายขอบเขต API Key ที่เดิมใช้สำหรับ Google Maps ให้เข้าถึง Gemini ได้โดยอัตโนมัติ โดยไม่มีการแจ้งเตือนที่ชัดเจนเพียงพอ ปัญหานี้สะท้อนความท้าทายใหม่ของยุค AI: ยิ่งระบบถูกเชื่อมต่อกันมากขึ้นเท่าใด ช่องโหว่ด้านความปลอดภัยก็ยิ่งขยายออกตาม COO ของ Google Cloud ยอมรับว่าแม้แต่ Google เองก็ยังเรียนรู้และปรับตัวกับความเสี่ยง AI Security อยู่แบบเรียลไทม์

## 2. รีวิว Amazon Bee: กำไล AI ที่บันทึกทุกบทสนทนา — น่าหลงใหลและน่ากังวลในเวลาเดียวกัน

Amazon Bee คืออุปกรณ์สวมใส่รูปแบบกำไลข้อมือราคา 49.99 ดอลลาร์ที่ Amazon เข้าซื้อกิจการมา และตอนนี้เริ่มวางจำหน่ายแบบกว้างขึ้นแล้ว ตัวอุปกรณ์ออกแบบมาเพื่อทำหน้าที่เป็นผู้ช่วย AI ส่วนตัวที่บันทึก ถอดเสียง และสรุปบทสนทนาตลอดทั้งวัน นักวิจารณ์จาก TechCrunch ทดลองใช้แล้วอธิบายความรู้สึกว่า "ทั้งหลงใหลและรู้สึกเกร็งเล็กน้อย" เนื่องจากอุปกรณ์ไม่เพียงแค่บันทึก Meeting Notes แต่ยังเชื่อมต่อกับอีเมลและปฏิทินเพื่อสร้างฉบับร่างหรือนัดหมายอัตโนมัติตามเนื้อหาที่พูดคุยกัน ด้วยค่าบริการ 19 ดอลลาร์ต่อเดือน Bee กำลังท้าทายนิยามใหม่ของ AI Personal Assistant และ Amazon มีแผนจะรวม Bee เข้ากับ Alexa ในอนาคต ซึ่งอาจปรับเปลี่ยนรูปแบบการโต้ตอบกับ AI ในชีวิตประจำวันอย่างสิ้นเชิง
