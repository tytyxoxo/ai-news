## 1. Alibaba สั่งห้ามพนักงานใช้ Claude Code หลังพบโค้ดแอบสอดส่องผู้ใช้จีน

TechCrunch รายงานว่า Alibaba เตรียมห้ามพนักงานใช้ Claude Code เครื่องมือเขียนโค้ดของ Anthropic ตั้งแต่วันที่ 10 กรกฎาคมเป็นต้นไป โดยจัดให้เป็นซอฟต์แวร์ความเสี่ยงสูงและให้เปลี่ยนไปใช้ Qoder เครื่องมือของบริษัทเองแทน สาเหตุมาจากการพบว่า Claude Code เคยตรวจสอบ time zone และ proxy server ของผู้ใช้เพื่อดูว่าเชื่อมโยงกับจีนหรือแล็บ AI จีนหรือไม่ ก่อนแนบเครื่องหมายพิเศษไปกับคำสั่งที่ส่งกลับไปยังเซิร์ฟเวอร์ของ Anthropic

เหตุการณ์นี้เกิดขึ้นหลัง Anthropic เคยกล่าวหากลุ่มที่เชื่อมโยงกับแล็บ Qwen ของ Alibaba ว่าใช้บัญชีปลอมเกือบ 25,000 บัญชีดึงข้อมูลจาก Claude กว่า 28 ล้านครั้งเพื่อ distill ความสามารถของโมเดล สะท้อนสงครามข้อมูลสองทางระหว่างสหรัฐฯ กับจีนที่ลามเข้าสู่เครื่องมือพัฒนาซอฟต์แวร์ในชีวิตประจำวัน สำหรับทีมวิศวกรรมที่พึ่งพา Claude Code นี่คือสัญญาณเตือนให้ตรวจสอบ telemetry ของเครื่องมือ AI อย่างละเอียดขึ้น และตอกย้ำว่าความไว้ใจในซัพพลายเชนซอฟต์แวร์ AI ข้ามพรมแดนกำลังเปราะบางลงเรื่อย ๆ

**จับตา:** ติดตามว่า Anthropic จะออกมาชี้แจงหรือแก้ไขพฤติกรรมการเก็บข้อมูลใน Claude Code อย่างเป็นทางการหรือไม่

## 2. Midjourney ยื่นศาลบังคับ Disney, Universal, Warner Bros. เปิดเผยการใช้ AI ภายใน

TechCrunch รายงานว่า Midjourney ยื่นคำร้องต่อศาลสหรัฐฯ เพื่อบังคับให้ Disney, Universal และ Warner Bros. ซึ่งเป็นโจทก์คดีลิขสิทธิ์ที่ฟ้อง Midjourney เปิดเผยว่าใช้ AI ภายในองค์กรอย่างไรบ้าง ทั้งแผนธุรกิจ งานวิจัย ชุดข้อมูลฝึกโมเดล และการนำเสนอต่อบอร์ดบริหารเรื่องการใช้ AI ทำ storyboard และคิดไอเดียงานสร้าง หลังศาลชั้นต้นเคยจำกัดขอบเขตการเปิดเผยไว้เฉพาะแอป AI ที่ผู้บริโภคเห็นเท่านั้น

กลยุทธ์ของ Midjourney คือการอ้าง "unclean hands" ว่าสตูดิโอเองก็ใช้แนวทาง AI คล้ายกันในการผลิตงาน จึงไม่ควรมีสิทธิฟ้องร้อง สะท้อนว่าคดีลิขสิทธิ์ AI ยุคนี้ไม่ได้เถียงกันแค่เรื่องข้อมูลฝึกโมเดลฝ่ายเดียวอีกต่อไป แต่ขยายไปถึงการตรวจสอบว่าทุกฝ่ายในอุตสาหกรรมใช้เทคโนโลยีเดียวกันอย่างไร คำตัดสินเรื่องขอบเขตการเปิดเผยข้อมูลนี้จะกลายเป็นบรรทัดฐานสำคัญของคดี AI-copyright ในอนาคต และอาจกดดันให้สตูดิโอใหญ่ต้องเปิดเผยการใช้ AI ภายในที่เคยเก็บเป็นความลับทางธุรกิจ

**จับตา:** ติดตามคำวินิจฉัยของผู้พิพากษาว่าจะขยายขอบเขตการเปิดเผยข้อมูลตามที่ Midjourney ร้องขอหรือไม่

## 3. สำรวจพบองค์กรเพียง 1 ใน 10 ตรวจจับ AI agent ที่ทำงานผิดพลาดใน production ได้ทันที

VentureBeat เผยผลสำรวจ VB Pulse Research จากองค์กรที่มีพนักงานตั้งแต่ 100 คนขึ้นไปจำนวน 145 แห่งในเดือนมิถุนายนที่ผ่านมา พบว่ามีเพียง 1 ใน 10 องค์กรเท่านั้นที่มีระบบตรวจสอบอัตโนมัติจับสัญญาณ AI model drift หรือความผิดปกติใน production ได้ทันที ขณะที่ 79% เคยได้รับความเสียหายทางการเงินหรือการดำเนินงานจริงจาก AI agent ที่ทำงานผิดพลาดแล้ว ส่วนใหญ่มาจาก shadow AI ที่พนักงานรันเองโดยไม่มีใครกำกับดูแล

ตัวเลขนี้ตอกย้ำสิ่งที่นักวิจัยเรียกว่า "Control Gap" คือช่องว่างระหว่างความเร็วในการนำ AI agent มาใช้งานจริงกับความสามารถในการมองเห็นและกำกับดูแลที่ตามไม่ทัน โดย 85% ขององค์กรมีแพลตฟอร์ม AI มากกว่าหนึ่งระบบที่ต่างอ้างตัวเป็นเลเยอร์หลัก ทำให้ policy และ log กระจัดกระจาย สำหรับทีม MLOps และ Security นี่คือเหตุผลที่ควรลงทุนในระบบ observability และ alerting เฉพาะสำหรับ agent ตั้งแต่วันนี้ ก่อนที่การขยายสเกลการใช้งาน AI agent จะสร้างความเสียหายที่ตรวจจับไม่ทันในระดับใหญ่ขึ้น

**จับตา:** ติดตามว่าผู้ให้บริการ AI แพลตฟอร์มรายใหญ่จะเริ่มผนวกเครื่องมือ monitoring แบบรวมศูนย์เข้ากับผลิตภัณฑ์หลักหรือไม่

## 4. โฆษณา AI วันชาติสหรัฐฯ ของ Google จุดกระแสวิจารณ์เรื่องการลดทอนประวัติศาสตร์

TechCrunch รายงานว่า Google เผยแพร่โฆษณาชุดใหม่ในโอกาสวันชาติสหรัฐฯ 4 กรกฎาคม สมมติให้บรรดา Founding Fathers มี Google Workspace ใช้ระหว่างร่างคำประกาศอิสรภาพ ให้ Gemini ช่วยจดบันทึกการประชุม ใช้ฟีเจอร์ช่วยออกแบบตราสัญลักษณ์ประจำชาติ และตอบปฏิเสธคำขอเข้าถึงเอกสารของกษัตริย์จอร์จที่ 3 ผ่านแชตบอต ก่อนเซ็นเอกสารด้วยลายเซ็นอิเล็กทรอนิกส์

แม้ยอดตอบรับใน YouTube และ Instagram จะออกไปในทางบวกเป็นส่วนใหญ่ แต่กระแสใน Bluesky กลับวิจารณ์อย่างหนักว่าโฆษณานี้ลดทอนความเสียสละของผู้ก่อตั้งประเทศให้กลายเป็นเรื่องตลกทางการตลาด สะท้อนความเสี่ยงที่แบรนด์เทคโนโลยีต้องเผชิญเมื่อพยายามผูก AI เข้ากับเหตุการณ์ประวัติศาสตร์ที่อ่อนไหว สำหรับทีมการตลาดและสื่อสารองค์กร นี่คือบทเรียนว่าการเล่าเรื่องคุณค่าทางอารมณ์สูงด้วย AI ต้องระมัดระวังเป็นพิเศษ เพราะกระแสตีกลับบนโซเชียลมีเดียเกิดขึ้นเร็วกว่าที่แคมเปญจะตั้งตัวทัน

**จับตา:** ติดตามว่า Google จะถอดหรือปรับแก้โฆษณาชุดนี้หลังกระแสวิจารณ์ขยายวงหรือไม่
