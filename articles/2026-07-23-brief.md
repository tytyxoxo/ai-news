## 1. OpenAI เปิดตัว Presence แพลตฟอร์ม AI agent ระดับองค์กร

OpenAI ประกาศเมื่อ 22 กรกฎาคม 2569 เปิดตัว Presence แพลตฟอร์มระดับองค์กรสำหรับติดตั้งและดูแล AI agent ด้านเสียงและแชท ให้ใช้งานได้ทันทีผ่านโปรแกรม limited GA โดยทีม Forward Deployed Engineers ของ OpenAI และพาร์ทเนอร์ระบบครบวงจรเป็นผู้นำการติดตั้ง ยังไม่เปิดแบบ self-service Presence รวมนโยบาย การเชื่อมต่อระบบ การประเมินผล และกระบวนการอัปเดตที่จำเป็นไว้ในที่เดียว ตัวอย่างจริงคือสายด่วนซัพพอร์ตภาษาอังกฤษของ OpenAI เอง ที่แก้ปัญหาลูกค้าได้เองถึง 75% โดยไม่ต้องพึ่งพนักงาน

Presence สะท้อนว่า OpenAI กำลังเปลี่ยนจากขายโมเดลเป็นขาย "ระบบ agent พร้อมใช้งานจริง" ให้องค์กร แก้ปัญหาที่ทีมไอทีส่วนใหญ่เจอคือต้องต่อ API ระบบรักษาความปลอดภัย และเครื่องมือประเมินผลเองทั้งหมด ธนาคาร BBVA ที่กำลังทดลองใช้บริการเสียงในเม็กซิโกเป็นตัวอย่างว่าองค์กรที่ถูกกำกับดูแลเข้มงวดเริ่มไว้ใจให้ agent จัดการงานลูกค้าโดยตรง แต่การไม่เปิด self-service หมายความว่าเฉพาะลูกค้าองค์กรใหญ่งบสูงเท่านั้นที่เข้าถึงได้ตอนนี้

**จับตา:** OpenAI Presence จะขยายสู่ลูกค้าองค์กรขนาดกลางแบบ self-service เมื่อใด

## 2. AMD ทุ่ม 5 พันล้านดอลลาร์ลงทุนใน Anthropic พ่วงดีลส่งมอบชิป

Bloomberg รายงานเมื่อ 22 กรกฎาคม 2569 ว่า AMD ตกลงลงทุนใน Anthropic สูงสุดถึง 5 พันล้านดอลลาร์ พร้อมข้อตกลงส่งมอบชิปกำลังผลิตสูงระดับหลาย gigawatt โดย Anthropic จะซื้อชิป Instinct MI450 รุ่นล่าสุดของ AMD มากถึง 2 gigawatt เริ่มตั้งแต่ครึ่งแรกของปี 2570 นับเป็นดีลฮาร์ดแวร์ AI ขนาดใหญ่ที่สุดดีลหนึ่งของ AMD ในปีนี้

ดีลนี้ทำให้ Anthropic มีซัพพลายเออร์ชิปสำรองนอกเหนือจาก Nvidia ที่ผูกขาดตลาดชิป AI มานาน ขณะที่ AMD ได้ลูกค้ารายใหญ่มายืนยันว่า MI450 แข่งขันได้จริงระดับ hyperscale ท่ามกลางภาวะขาดแคลนกำลังผลิตชิปทั่วอุตสาหกรรม สำหรับองค์กรที่พึ่งพา Claude ซัพพลายชิปที่หลากหลายขึ้นอาจแปลเป็นเสถียรภาพด้านต้นทุนที่ดีขึ้น ส่วนวงการชิปมองว่านี่คือสัญญาณว่า AMD กำลังไล่ตาม Nvidia ในสมรภูมิ AI inference จริงจังขึ้น

**จับตา:** AMD จะประกาศลูกค้ารายใหญ่รายอื่นเพิ่มเติมสำหรับ Instinct MI450 หรือไม่

## 3. จีนเดินเกม "AI for All" ท้าทายแนวกีดกันของสหรัฐฯ

Bloomberg รายงานเมื่อ 22 กรกฎาคม 2569 ว่าโมเดล AI จีนที่แข่งขันได้สูงขึ้นเรื่อยๆ กำลังสร้างความกังวลในวอชิงตัน ท้าทายแนวทางกีดกันแบบเดิมของสหรัฐฯ ผู้แทนการค้าสหรัฐฯ ระบุว่ากำลังจับตาใกล้ชิดว่าจีนเผยแพร่เทคโนโลยี AI ของตนอย่างไร ขณะที่ Scott Bessent รัฐมนตรีคลังกล่าวว่าสหรัฐฯ อาจคว่ำบาตรโมเดลต่างชาติที่พบว่าขโมยทรัพย์สินทางปัญญาของสหรัฐฯ

กลยุทธ์ "AI for All" ของจีน ที่เน้นเผยแพร่โมเดลโอเพนซอร์สราคาถูกให้ทั่วโลกใช้ได้ กำลังบั่นทอนแนวควบคุมส่งออกชิปของสหรัฐฯ เพราะแม้จำกัดฮาร์ดแวร์ได้ แต่จีนยังส่งออก "ความสามารถ" ผ่านตัวโมเดลได้อยู่ดี นักพัฒนาที่มองหาโมเดลราคาถูกจะมีทางเลือกมากขึ้น แต่ก็เสี่ยงด้านกฎระเบียบหากสหรัฐฯ คว่ำบาตรจริงจัง

**จับตา:** สหรัฐฯ จะออกมาตรการคว่ำบาตรที่เป็นรูปธรรมต่อโมเดล AI จีนหรือไม่ และจะกระทบผู้ใช้นอกจีนอย่างไร

ที่มา: [Bloomberg](https://www.bloomberg.com/news/articles/2026-07-22/china-s-ai-for-all-offensive-defies-us-containment-playbook)

## 4. Alphabet อัดงบลงทุน AI ปี 2569 เพิ่มเป็น 2 แสนล้านดอลลาร์

Bloomberg รายงานเมื่อ 22 กรกฎาคม 2569 ว่า Alphabet บริษัทแม่ Google ปรับเพิ่มประมาณการงบลงทุนปี 2569 เป็น 1.95-2.05 แสนล้านดอลลาร์ จากเดิมไม่เกิน 1.9 แสนล้านดอลลาร์ เพื่อเร่งสร้างกำลังประมวลผลรองรับความทะเยอทะยานด้าน AI ผลประกอบการล่าสุดพบว่ารายได้ธุรกิจ cloud ทำได้ดีกว่าคาด แต่รายได้จากธุรกิจค้นหาพลาดเป้าเล็กน้อย

การอัดงบลงทุนเพิ่มแม้รายได้ค้นหาสะดุดเล็กน้อย สะท้อนว่า Alphabet เชื่อว่าการลงทุนโครงสร้างพื้นฐาน AI ยังจำเป็นต่อการรักษาตำแหน่งผู้นำ สำหรับตลาดชิปและศูนย์ข้อมูล นี่เป็นสัญญาณบวกเพราะ hyperscaler รายใหญ่ยังไม่ชะลอการลงทุน ธุรกิจที่พึ่งพา Google Cloud หรือ Gemini API ควรคาดหวังว่ากำลังประมวลผลจะขยายตัวต่อเนื่อง

**จับตา:** นักลงทุนจะยังคงอดทนรอผลตอบแทนจากการลงทุน AI มหาศาลของ Alphabet ต่อไปอีกนานแค่ไหน

ที่มา: [Bloomberg](https://www.bloomberg.com/news/articles/2026-07-22/alphabet-posts-cloud-sales-beat-slight-miss-on-search-revenue)

## 5. ทำเนียบขาวกล่าวหา Moonshot AI ดึงความรู้จาก Claude Fable ผ่านชิปในไทย

Blognone รายงานเมื่อ 22 กรกฎาคม 2569 ว่า Michael Kratsios ผู้อำนวยการสำนักนโยบายวิทยาศาสตร์และเทคโนโลยีทำเนียบขาว กล่าวหาว่า Moonshot AI สตาร์ทอัปจีนใช้เทคนิค distillation ดึงความรู้จากโมเดล Claude Fable ของ Anthropic พร้อมเข้าถึงเซิร์ฟเวอร์ชิป GB300 ของ Nvidia ในไทย ซึ่งเป็นชิปรุ่น Blackwell ที่ห้ามขายให้บริษัทจีนโดยตรง เพื่อนำไปฝึกโมเดล Kimi K3

ข้อกล่าวหานี้เกิดขึ้นหลัง Kimi K3 เขย่าวงการจนมูลค่าบริษัทเทคสหรัฐฯ หายไปหลายแสนล้านดอลลาร์เมื่อสัปดาห์ก่อน กรณีนี้ตอกย้ำว่าสมรภูมิ AI สหรัฐฯ-จีนขยับจากแข่งเทคโนโลยีสู่การเมืองเรื่องห่วงโซ่อุปทานชิปและ IP รัฐมนตรีคลัง Bessent ย้ำว่า distillation แบบอุตสาหกรรมข้ามเส้นสู่ IP theft จะนำไปสู่มาตรการคว่ำบาตรและขึ้นบัญชี Entity List

**จับตา:** ทำเนียบขาวจะเปิดเผยหลักฐานยืนยันข้อกล่าวหาการเข้าถึงชิป GB300 ในไทยของ Moonshot ต่อสาธารณะหรือไม่
