# skill: daily-ai-news

## ขั้นตอนที่ 0 — เตรียมการ

1. ตรวจสอบว่า GitHub connector พร้อมใช้งาน — ถ้าไม่มีให้หยุดและแจ้งสาเหตุ
2. กำหนดเวลาปัจจุบันตาม timezone Asia/Bangkok → `NOW` และ `TODAY` = วันที่ (YYYY-MM-DD)
3. กำหนด `OUTPUT_FILE = articles/{TODAY}-brief.md`
4. ตรวจสอบว่า `OUTPUT_FILE` มีอยู่แล้วหรือไม่ — ถ้ามีและมีเนื้อหาครบให้หยุด แจ้งว่า "ไฟล์วันนี้มีอยู่แล้ว" โดยไม่ต้อง overwrite

## ขั้นตอนที่ 1 — อ่านรายการข่าว

อ่าน `feeds/candidates.json` จาก **branch `feeds`** (ไม่ใช่ main) ผ่าน GitHub connector — ไฟล์นี้สร้างโดย GitHub Actions (`fetch-feeds.yml`) ทุกชั่วโมง (นาทีที่ 17 — GitHub cron อาจช้าหรือข้ามบางรอบ) จาก RSS ของแหล่งใน `reference/trusted-sources.md` และตัดข่าวที่ URL เคยลงใน `articles/` ไปแล้ว

**ห้ามใช้ WebSearch หรือ WebFetch** — session นี้เข้าเว็บข่าวไม่ได้ (โดน network allowlist บล็อก) ข้อมูลทั้งหมดต้องมาจาก `candidates.json` เท่านั้น

โครงสร้าง: `generated_at` (เวลาที่สร้าง, UTC), `failed_feeds` (feed ที่ดึงไม่ได้รอบนี้), `items[]` แต่ละข่าวมี `source`, `title`, `url`, `published` (ISO 8601 จาก feed จริง), `summary` (เนื้อข่าวจาก feed หรือหน้าบทความ ตัดที่ 1,200 ตัวอักษร)

ถ้า `generated_at` เก่ากว่า `NOW` เกิน 12 ชั่วโมง หรืออ่านไฟล์ไม่ได้ → ใช้รูปแบบ "กรณีไม่มีข่าวผ่านเกณฑ์" สาเหตุ: `candidates.json ไม่อัปเดต (generated_at: {ค่า})`

## ขั้นตอนที่ 2 — คัดกรองและเลือกข่าว

กรองด้วยเงื่อนไขเหล่านี้:
1. **36h filter** — `published` อยู่ภายใน 36 ชั่วโมงก่อน `NOW` (เทียบเวลาแบบมี timezone — `published` เป็นค่าจริงจาก feed ไม่ต้องยืนยันซ้ำ) ใช้ 36 ไม่ใช่ 24 เพื่อไม่ให้ข่าวหล่นหายเมื่อ candidates ช้าไปหลายชั่วโมง — กันข่าวซ้ำด้วยข้อ 2 แทน
2. **Dedup** — `url` ต้องไม่อยู่ในไฟล์ `articles/` ล่าสุด 2 ไฟล์บน main (Actions ตัดข่าวที่เคยลงไปแล้ว แต่ถ้า candidates สร้างก่อน brief เมื่อวานจะยังหลุดมาได้)
3. **เป็นข่าว AI จริง** — feed ทั่วไป (Bloomberg, ข่าวไทย ฯลฯ) ถูกกรองด้วยคีย์เวิร์ดหยาบๆ มาแล้ว จะมีข่าวที่แค่เอ่ยถึง AI ปนมา ให้ตัดข่าวที่ AI ไม่ใช่ประเด็นหลักทิ้ง
4. **เนื้อหาพอเขียน** — `summary` ต้องมีข้อเท็จจริงพอเขียนย่อหน้าที่ 1 โดยไม่ต้องเดา ถ้าสั้นมาก (ไม่กี่ประโยค) ให้ข้ามไปเลือกข่าวอื่นก่อน ถ้าจำเป็นต้องใช้ ให้เขียนสั้นลงตามข้อมูลที่มี ห้ามเติมรายละเอียดที่ไม่อยู่ใน `summary`

เลือกสูงสุด 5 ข่าวที่ผ่านทุกเงื่อนไข โดย:
- ข่าวเดียวกันจากหลายแหล่ง เลือกตาม "ลำดับการเลือก" ใน `reference/trusted-sources.md` (official ก่อนสื่อ) และนับเป็นข่าวเดียว
- มีแหล่งไทยอย่างน้อย 1 ข่าว ถ้ามี
- มีแหล่งต่างประเทศอย่างน้อย 3 ข่าว
- arXiv เป็น preprint ใช้เฉพาะงานที่มีนัยสำคัญจริง และต้องระบุว่ายังไม่ผ่าน peer-review
- ห้ามผ่อนเกณฑ์เพื่อให้ครบ 5 — ถ้าได้ 3 ก็ส่งแค่ 3

## ขั้นตอนที่ 3 — วิเคราะห์เชิงลึก

สำหรับแต่ละข่าว ให้คิดวิเคราะห์จาก 3 มุมมองนี้ไว้ก่อน (ใช้ในขั้นเขียนเท่านั้น ไม่ต้องเขียนแยก):
- **มุมวิชาการ** — งานวิจัยหรือแนวคิดอะไรอยู่เบื้องหลัง มีข้อจำกัดหรือสมมติฐานอะไรที่ควรระวัง
- **มุม developer** — กระทบกับเครื่องมือ workflow หรือ stack อย่างไร มีอะไรนำไปใช้ได้จริงทันที
- **มุมผู้ใช้/ธุรกิจ** — เปลี่ยนแปลงการทำงานหรือชีวิตประจำวันอย่างไรในทางปฏิบัติ

## ขั้นตอนที่ 4 — เขียนบทความ

เขียนสไตล์นักวิเคราะห์ที่คนทั่วไปอ่านได้ แต่ลึกพอที่คน tech จะได้ประโยชน์

รูปแบบของแต่ละข่าว:
- **ย่อหน้าที่ 1** (60–80 คำ): ที่มา บริบท และสิ่งที่เกิดขึ้น
- **ย่อหน้าที่ 2** (60–80 คำ): ความสำคัญและผลกระทบ — สอดแทรกมุมมองจากขั้นตอนที่ 3 อย่างเป็นธรรมชาติ ไม่ต้องระบุว่ามาจากมุมไหน
- **จับตา:** (1 ประโยค): สิ่งที่ควรติดตามต่อหรือนำไปลองใช้จริง

ห้ามใช้ bullet point — ทุกส่วนต้องเป็นย่อหน้าต่อเนื่องเท่านั้น

## ขั้นตอนที่ 5 — บันทึกขึ้น GitHub

รูปแบบไฟล์:

```
---
date: {YYYY-MM-DD}
---

## 1. {หัวข้อข่าว}

{ย่อหน้าที่ 1}

{ย่อหน้าที่ 2}

**จับตา:** {ประโยคเดียว}

ที่มา: [{ชื่อเว็บ}]({URL})

---

## 2. {หัวข้อข่าว}

...

---

_สร้างโดย Claude Code Routine เวลา 09:00 น._
```

แต่ละข่าวจะถูกส่งเป็นข้อความ LINE แยกกันคนละบับเบิล (`scripts/line_notify.py` แยกตามเส้น `---`) — ต้องคั่นทุกข่าวด้วย `---` ตามรูปแบบข้างบน และห้ามใช้ `---` ภายในเนื้อข่าว

ใช้ GitHub connector commit `OUTPUT_FILE` ตรงลง branch: main — ห้ามสร้าง branch ใหม่ ห้าม commit ลง branch `feeds` ห้ามใช้ Bash หรือ git CLI ใดๆ

## กรณีไม่มีข่าวผ่านเกณฑ์

```
---
date: {YYYY-MM-DD}
---

ไม่มีข่าว AI ใหม่ที่ผ่านเกณฑ์ในวันนี้
สาเหตุ: {ระบุ: 36h filter / dedup / ไม่ใช่ข่าว AI / candidates.json ไม่อัปเดต}

_สร้างโดย Claude Code Routine เวลา 09:00 น._
```

## ข้อห้าม

- ห้ามแต่งหรือเดา URL — ใช้ `url` จาก `candidates.json` ตรงตัวเท่านั้น
- ห้ามใช้ WebSearch / WebFetch — ใช้ข้อมูลจาก `candidates.json` เท่านั้น
- ห้ามใช้ Bash, git CLI หรือ shell ใดๆ
- ใช้ timezone Asia/Bangkok เสมอ
